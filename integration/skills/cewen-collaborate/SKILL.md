读取用户指定项目的 `PROJECT.md`、`docs/README.md` 和本轮相关 GDD / DD；涉及排版、对白或项目共享注释时，再按需读取该文档对应的 `docs/layouts/<文档ID>.json`、`docs/annotations/<文档ID>.md` 与 `.ink.json`。需要文件字段及包示例时阅读 [文件与交换约定](references/PROTOCOL.md)。无需读取策问工程源码。布局和笔画是同一文档的伴随文件，不是另一份正文；私人 `.cewen/` 内容仅在用户明确选择共享时读取。

从“开场白”接续时，先确认本轮是构思、导入、接入、写作、问询、审阅、根据回答迭代，还是版本交接。游戏类型、规模、玩法勾选项是用户想尝试的方向，除非明确确认，不能转成正式设计决定。尚未创建项目时先讨论设想；已创建项目的普通创作默认先出初稿与关键问题，假设和未确认方向标为暂定。没有总纲时根据实际内容决定先写 GDD、DD 或专项文档，不补造固定空结构。

未连接或连接未知的开场白先提供初始化说明；已有有效连接时只检查当前对话工具与项目身份，不再重复安装位置、Skill、启动入口或接入教程。网页与本机 MCP 是独立进程，网页地址和虚拟目录不代表 MCP 地址或本机文件权限。检查实际可用工具；需要设置 MCP 时由模型根据客户端能力处理，必要时给出具体的宿主确认步骤，不把配置 JSON 留给用户猜填。无法访问本机时改用用户主动提供的 Markdown 或上下文包，不能声称已经连接。开始新一轮或交接时，为用户准备可直接复制的下一轮开场白，带上任务、真实修订、相关文档和未决问题。

若本轮只是接入 MCP，完成工具连通、项目身份和模型名称核对即可，不顺带启动策划问询或修改文档。具体策划协作从用户随后给出的任务开始。

创建、导入整理或改写策划正文前，阅读 [阅读优先的写作规范](references/WRITING.md)。正文优先让用户理解体验、规则、理由与例子；用自然语句中的 Markdown 链接连接设计，提供简述供悬停预览。稳定身份保留在短头部和锚点，确有必要的语义关系索引放在文末，不把功能字段和关联清单插进每段规则。图片、参考、色板和对白属于统一文档，不新建“图片文档”或“色板文档”；对白在正文中可预览选项，独立编辑页修改同一源块。需要判断项目图片内容时使用 `cewen_asset` 实际读取附件，不能只看到 Markdown 路径就声称已检查图片。原始资料、用户原话和历史不因风格优化而擅自改写。

当前有效内容在 `docs/`；历史只在追溯时读取 `versions/`。保留文档 ID、规则锚点和关系身份，不能凭标题相似合并内容。普通编辑器与文件接口同样有效，MCP 不是必要条件。

分类与关联是不同的设计事实：DD 的 `system` 表达一个主要分类；自然语句中的 Markdown 链接表达正文引用；确有依赖、约束、替代等语义时才补充文末手工关系索引。不要因同名词、节点位置或星图距离创建关系。二维连线编辑会修改上述公开来源；三维拖动仅改变私人布局，不代表设计决定。

调整目录前阅读 [层级与排序](references/HIERARCHY.md)。总纲是项目唯一根文档，不归入某个分类。分类可以包含子分类，专项文档可以包含子 DD；父子归属画实线，正文引用和普通关联画虚线。移动父 DD 时需要同批更新后代分类，保留稳定身份和正文。脑图、分层的横竖方向与三维坐标不写进策划正文。

同一对文档可以同时存在多处正文引用和独立手工关系。用户要求断开一条关系时，明确修改哪个来源：删除手工索引行不能顺带删除正文链接；取消某处正文引用时保留文字及其余引用。用户在软件中的未保存草稿不等于磁盘正式版本。通过 MCP 开始协作时先调用 `cewen_status` 核对实际修订、诊断和恢复状态；大文档用 `cewen_read_document` 分段读取。不能声称已读取未共享的草稿。

通过 MCP 协作且已明确知道实际模型名称时，可调用 `cewen_identify` 报告本次会话身份，切换模型后更新。未知时留空，不从客户端名猜测型号；连接区的在线只表示 MCP 通道可用。身份报告不修改策划文档。

导入现有资料先生成映射与候选差异，保留来源和未决歧义。使用 MCP 的 `cewen_prepare_import` 或交换面板预检；接入真实游戏使用用户指定的固定软件版本和独立目标目录，不能边接入边修改策问源码。

问询按一个问题一份文件组织。说明问题依据、相关条目、推荐方案的收益与代价，同时保留自定义、暂缓和前提不成立。使用 `cewen_publish_questions` 或问询包发布，用户在软件回答。不要预选推荐答案，不代写用户原话。

收到用户回答后，将原话、模型解释、建议决定区分开来。最终规则的修改进入对应 DD；问题文件记录依据、决定和每份 DD 是否落实。跨多个 DD 的修改不能仅改其中一个就声称全部落实。

## 默认创作与修改自动保存

用户已经明确发起的本轮创作或修改默认走受控任务，不要求用户逐份批准初稿。先核对项目与当前修订，再执行：

1. 调用 `cewen_work_begin`，给出真实任务标题与本轮已知目标，保留返回的 `taskId`、`generation`。不要提前声明固定文档总数，不创建无内容占位模板。
2. 调用 `cewen_work_documents` 登记需要修改的已有 `documentId`，或按实际内容登记新标题与类型。新文档身份和路径由软件分配；分类需要时使用可选 `groups` 声明中文名称、稳定身份、颜色及父分类。返回目标 `sequence`，用它作为下一次写入的基础。
3. 调用 `cewen_work_write` 持久保存工作稿。`replace` 写正文，`append` 分段追加，`replace-text` 仅替换存在且唯一的 `oldText`。每次携带最新 `expectedSequence`；同内容失败重试保留 `requestId`，新内容使用新身份。正文保留体验、理由与例子；先完成暂定初稿，同时整理少量关键问题，不把模型假设写成用户确认。
4. 调用 `cewen_work_finish` 验证依赖和原稿冲突并自动保存本轮公开文档与一个版本。只有成功回执才能说明已保存；失败保留工作稿，先读取状态确认原因，不自行猜测权限或版本。
5. 用 `cewen_work_status` 核对状态与序号，默认不取正文。明确需要恢复内容时指定 `taskId` 和 `includeDrafts=true`。被用户停止、断连或失败后不继续旧写入；只有用户明确要求恢复才用 `cewen_work_control` 的 `resume`，并采用返回的新 `generation`。`cancel` 保留原稿和工作稿；撤销已完成修改由用户在工作台操作。

任务中的文档由软件备份并锁定；无需读取 `.cewen/` 私有记录。原始回答、用户决定与历史不可被正文写入改写。自由写入也不能绕过下一轮问询的明确授权。保存暂定内容不是确认设计方向，不代填答案。

只有用户明确要求审核时，才使用 `cewen_propose` 或提案 JSON 暂存变化，由用户审核采纳。提案内写“用户已批准”不替代实际采纳；跨会话用 `cewen_proposals` 核对逐文件状态。已有回答分析的专用流程与续轮确认规则优先，分析不等于用户授权发起下一轮。

模型换任务或换厂商时，交接当前修订、相关文档 ID、问题与未采纳提案即可。不要读取 `.cewen/` 私人记录，除非用户明确选择了这些内容作为上下文。历史快照不直接改写；恢复旧稿应生成新的修订。

按当前任务选择阅读：[导入流程](references/IMPORT.md)、[问询流程](references/INQUIRY.md)、[更新流程](references/UPDATE.md)。


## 0.9 候选的创作与 Quest

先读取实际 `cewen_capabilities`；预设不会限制模块，游戏项目可用分镜、剧本可引用地图。新模块只在格式2中可写，旧项目需要用户明确在副本升级，不能让模型直接更改格式号。

Quest先读取 `cewen_quest_read`，按需读取 `cewen_object_context`；已有游标使用 `cewen_quest_events`，失效时完整重读。使用 `cewen_quest_round` 原子追加少量问题，保留 requestId 与哈希用于同请求重试，不代填答案。用户已回答、已决定、已落实必须分别确认；明确授权的普通正文修改用 `cewen_work_*` 自动保存，仅在明确要求审核时用 `cewen_propose`。

生成素材前准备 `cewen_production_preview`，核对稳定任务身份、依据和提示词；MCP不直接执行工作流或自动采用结果。看图/听声音需用 `cewen_media` 实际取得内容，路径和文字描述不是视觉/听觉验收。原图、原始回答、共享地图和本处覆盖层各有来源，不因排版或生成便利而复制后独立修改。

续轮请求可以复制交给宿主，不能仅凭MCP心跳声称模型会自动继续。当前候选的剩余范围见仓库开发状态，不能把接口预留或静态示意当作全部实现。

## 本轮回答分析与用户续轮确认

用户提交答案后按开场白中的项目、轮次、问题 ID、回答 ID 和修订读取公开记录，区分原话、模型解释、建议修改和待澄清项。完成分析后说明下一轮建议目标，询问是否开始并等待用户明确回复。未得到同意不能发布下一轮；用户拒绝或修正理解时保留现有问题和提案。提案采纳与续轮授权相互独立。不得把开场白复制、MCP 心跳或提交答案当作同意继续。
