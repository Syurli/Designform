# Q-001：休息是否消耗补给？

## 问题背景

休息同时关联时间与资源，需要明确两者如何共同影响路线选择。

## 可选方案

- A：消耗少量补给。推荐理由：让休息与探索使用同一资源约束；代价：需要控制管理负担。
- B：只消耗时间。收益：容易理解；代价：需另行明确时间压力。
