# 地图结构

用少量地点和明确的通路组织探索选择。

<a id="places"></a>

## 地点与入口

区域由入口、若干观察地点和终点组成，每个地点都有可阅读的环境说明。[环境遭遇](DD-004_环境遭遇.md)发生在这些地点中；玩家离开遭遇后回到地点，继续选择路线。

<a id="paths"></a>

## 路线选择

相邻地点之间可以有耗时不同的路线，玩家选择前能看到基本代价。耗时遵循[时间节奏](DD-003_时间节奏.md)；出发准备按[资源取舍](DD-002_资源取舍.md)展示所需补给。时间节奏给出统一的行动尺度，地图不另设一套计时规则。

<a id="visibility"></a>

## 探索信息

尚未到达的地点只展示轮廓。通过[先观察再行动](DD-004_环境遭遇.md#observe)确认的信息会更新地点列表，并写入[发现记录](DD-005_发现记录.md)。

<a id="rest"></a>

## 休息地点

休息地点允许整理记录和恢复状态，具体[休息成本](DD-002_资源取舍.md#rest-cost)仍待讨论。休息推进的时间沿用[行动推进时间](DD-003_时间节奏.md#step)，不重复定义。
