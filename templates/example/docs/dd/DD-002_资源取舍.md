# 资源取舍

资源规则为[地图结构](DD-001_地图结构.md)中的路线选择提供可理解的代价。玩家在出发前能理解携带与消耗之间的取舍。

<a id="supply"></a>

## 补给用途

补给用于旅程中的准备和部分行动，界面始终展示当前数量，并受[携带上限](#capacity)约束。

<a id="capacity"></a>

## 携带上限

玩家有明确的携带上限；上限只约束示例补给，不暗示任何复杂容器系统。

<a id="rest-cost"></a>

## 休息成本

设计状态：待确认

休息是否消耗补给仍待讨论，不能将推荐方案当作已经确定的规则。

### 相关问题

[Q-001 休息是否消耗补给](../questions/Q-001_休息成本.md)。

<a id="budget"></a>

## 出发前的准备

出发前展示[路线选择](DD-001_地图结构.md#paths)的预估时间和补给需求，并提示预计跨越的[白昼与夜晚](DD-003_时间节奏.md#day)，帮助玩家理解不同路线。
