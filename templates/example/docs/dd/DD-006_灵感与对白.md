# 灵感与对白

旅程不只由走过的路组成。玩家在休息地点听见一段话，再从自己的观察里选一句回应；谈话留下可回想的线索，但不替玩家决定下一站。

<a id="moment"></a>

## 路边的小停顿

当玩家抵达[休息地点](DD-001_地图结构.md#rest)，一位整理路牌的旅人会提起今天的风。对话不判定答案好坏，两种回应都让旅人补上一句观察，随后回到路线选择。玩家当时看到的景物可写进[发现记录](DD-005_发现记录.md#discovery)，供后续回顾。

下面这段对白是一个可点击选项的小场景。阅读时可以顺着任一回应走到结束；编辑时可调整台词和选项，但不应把节点在画布上的位置当作剧情顺序。

```cewen-dialogue
kind: dialogue
id: dlg-roadside-sign
title: 路牌旁的风
start: traveler
nodes:
  - id: traveler
    type: line
    speaker: 旅人
    text: 我每天都擦这块路牌。风一来，字上的灰又落回原处。你今天在路上看见了什么？
    choices:
      - id: choice-river
        text: 河边的石头像刚洗过一样亮。
        to: river-reply
      - id: choice-shade
        text: 山影比早晨走得还快。
        to: shade-reply
  - id: river-reply
    type: line
    speaker: 旅人
    text: 那就记住它亮起来的时候。明天经过，也许水已经换了颜色。
    next: farewell
  - id: shade-reply
    type: line
    speaker: 旅人
    text: 影子替我们量了路。等它碰到路牌，就该找个地方歇脚了。
    next: farewell
  - id: farewell
    type: end
    text: 旅人扶正路牌，玩家带着自己的观察继续前行。
```

<a id="mood"></a>

## 黄昏的颜色

这组颜色用于描述路牌旁逐渐安静下来的黄昏：暖色留给木牌和最后一线日光，冷色留给远山与河面。它是人工选择的设计意向，没有绑定源图片，也不声称来自图片提色统计。正式美术可在后续根据场景调整。

```cewen-palette
kind: palette
id: pal-roadside-dusk
title: 路牌旁的黄昏
colors:
  - id: dusk-amber
    hex: "#C5935F"
    role: 主色
    intent: 木牌上留存的夕照
  - id: dusk-blue
    hex: "#526B78"
    role: 辅色
    intent: 远山与将暗的天空
  - id: dusk-river
    hex: "#83A4A0"
    role: 点缀
    intent: 河边石面反射的微光
  - id: dusk-ink
    hex: "#35414A"
    role: 中性色
    intent: 路牌文字与阴影
```

<a id="return"></a>

## 回到旅程

对白结束后玩家回到[路线选择](DD-001_地图结构.md#paths)。这段谈话不改变路线代价；离开后的时间仍按[行动推进时间](DD-003_时间节奏.md#step)记录。若玩家愿意，旅程回顾可以把这一句观察与当时走过的地点放在一起。
