# 发现记录

记录已经发现的内容，并让回顾成为下一次选择的依据。

<a id="discovery"></a>

## 发现条目

首次理解一个地点或现象后，将可确认的信息写入旅程笔记，并保留对应的[地点与入口](DD-001_地图结构.md#places)。

<a id="index"></a>

## 分类检索

笔记可按地点和主题浏览，同一发现不因为多个分类而复制。

<a id="review"></a>

## 旅程回顾

旅程结束展示路线、[旅程时间记录](DD-003_时间节奏.md#timeline)和主要发现，不自动给玩家贴上好坏评价。

<a id="unlock"></a>

## 后续探索线索

部分发现提供新的探索线索，是否立即开放新地点仍由[地图结构](DD-001_地图结构.md)决定。线索不会自动揭露全部[探索信息](DD-001_地图结构.md#visibility)。
