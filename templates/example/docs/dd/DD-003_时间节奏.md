# 时间节奏

通过离散行动推进时间，让代价在选择前可以理解。

<a id="step"></a>

## 行动推进时间

移动、观察和休息各自推进一段时间，暂不填入未经验证的具体数值。

<a id="day"></a>

## 白昼与夜晚

时间阶段改变环境描述和部分地点的[探索信息](DD-001_地图结构.md#visibility)，不直接代表失败。

<a id="weather"></a>

## 天气提示

天气变化提前给出文字提示，具体影响可在后续问询中展开。

<a id="timeline"></a>

## 旅程时间记录

旅程记录按[行动推进时间](#step)的顺序标记时间，用于[旅程回顾](DD-005_发现记录.md#review)，帮助玩家理解自己的选择。
