# 虚构创作示例来源

这些示例只用于策问 0.9 开发与演练，不包含用户的真实游戏、剧本、私人草稿或对话。

- 六类预设与对象数据在 `shared/creative/presets.ts`，预设只初始化内容，不限制模块。
- 二维地图及分镜图由 `scripts/generate-demo-media.mjs` 的程序化绘制产生，明确标注示意用途；不是最终影视概念美术。
- `demo-voices.json` 包含八段用 eSpeak Mandarin 临时合成、经 ffmpeg 转换的演示 MP3，以 base64 存放。台词为本任务编写的虚构短句，不克隆真人声音。eSpeak / ffmpeg 可执行文件及模型并不随此源码交付。
- 构建前生成 `shared/creative/sample-media.generated.ts`，生成文件忽略；正式代码按需加载它，不使用 CDN。
- 示例提问、原始回答和采纳来自显式标记的演示链。创建示例不会表示真实用户已经确认这些决定，也不会发起外部模型调用。

综合样例“雾港来信”是主要验证夹具，涵盖地图在战斗、剧情、分镜三种位置的使用，以及多轮 Quest、部分落实、素材候选和有声排演。当前样例的部分跨预设内容复用同一虚构背景；独立题材的最终剧本、美术和配音润色仍待人工验收后完善。
