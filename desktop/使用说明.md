# 策问 Designform 0.9.4

百舸 · 本地游戏策划与 LLM 协作工作台。文档格式 1 / 2，接口协议 1。

## 文档工作台

- 应用菜单、连接状态和主题合入窗口标题栏；视图与项目操作共用下一行，画布工具与文档标签共用一行。
- 分类与文档使用块状双栏；分类在原栏向下展开，底部路径只作数据显示，收藏与最近各有独立范围。
- 按住条目约 250 毫秒才显示把手并开始拖动。文档列表内拖动调整展示顺序，拖入正式分类改变归属，拖入总置顶区增加快捷入口。
- 文档工作区的目录修改先暂存，“文件 → 保存全部文档与结构”后写入项目。示例始终在会话内编辑，保存需要另存为。
- 本包为 0.9.4。官方下载附件 SOURCE.json 记录发行来源，本机安装维护另记录 LOCAL_BUILD.json；版本以关于页及来源记录核对。

## 文档编写与收藏精简

- 卡片库只展示文档，滚轮可翻页；触控板连续滑动只切换一页。卡片不再显示分类名称，仍保留创建、最后编辑和版本信息。
- 文档默认右键保留卡片关系预览、改名、条目颜色及更多操作。星标、图钉继续通过文档右侧图标操作；更多操作可批量加入收藏分类。
- 旧集合在打开项目时并入个人收藏分类，保留成员、层级、说明与顺序。一篇文档可以属于多个收藏分类；原整理记录及项目正文不被迁入操作改写。
- 两种视图右侧上方是文字／格式刷工具，下方约三分之一是名称、标签、状态和文件位置。修改属性先进入草稿；按 Ctrl+S 保存当前文档。原用途分类使用标签表达。桌面点击文件位置打开所在文件夹。
- 单击正文直接编辑，沿用阅读时的字体、字号和排版；自由视图点击块外空白退出。自由文本块内回车只换行，空白处右键插入文字、图片或引用。
- 拖目录文档到文档视图会插入带引用颜色的标题链接，拖到自由视图则在松手位置插入独立引用块。两种方式都不复制或改写源文档。
- 图片框随图片比例适配；单击或右键图片可重新导入，保留块身份。附件随当前文档保存，取消文件选择不改正文。

## V2.2 文档与问答优化（0.9.3）

回答分析开场白只保留项目、版本、题数和短读取入口。模型用 Q/D 短号关联问题与文档，按需读取正文；逐题 UUID、hash 及重复轮次不再展开。软件自动补全提案的真实路径与保存基准。既有 MCP 可以直接透传新读取引用，无需为分析重启客户端；没有 MCP 时使用 `策问CLI.cmd answers 项目短号 "回答引用"`。

文档栏追加版：分类原位展开并汇总下级文档，默认彩条收起，鼠标靠近后挤压文档区展开；左上按钮切换固定、标准、抽屉三种样式。任意深层分类限制横向缩进并压缩祖先行，右末端箭头控制子分类，右键菜单期间不收起。顶栏显示当前分类与颜色，总置顶标题空闲显示虚线，靠近才展开文字。文档右侧保留星标和图钉；四种排序同步分页卡片库。长按文档后拖到总置顶区增加快捷入口，原列表仍显示文档。收藏和最近独立于正式分类，收藏支持多分类成员。公开手工顺序需要保存全部；个人偏好立即保存。

- 已有文档默认文档视图；自由视图使用同一份草稿与撤销链。两种视图默认可直接编辑，右上锁定按钮保护当前文档，解锁恢复编辑。文档锁是本机个人偏好，历史版本始终只读。
- 自由视图文本框按内容自然伸缩，手工调整的尺寸保留；进入编辑时保持原尺寸，编辑框与字体浮框跟随深浅主题。网格覆盖整个画布视口并跟随平移、缩放。
- 星图拖分类会逐层弹性牵引下级分类、文档与小节；固定节点截断该支牵引。系统分层按真实深度排列，同层并排；减少动画时直接跟随。
- 卡片库压缩标题区、按可用空间分页，展示创建、最后编辑及最近变更版本；双击卡片或目录文档直接打开策划案。保存当前阅读视图移到顶部“视图”菜单。
- 块头约 20px；拖动手柄调整位置。拖入标题的“归入此章节”接收区才关联，拖入底部“文档直属内容”区解除；普通移动不改归属或阅读顺序。
- 在预览打开“调整顺序”拖动段落／章节，归属保持不变。章节携带子树；直属内容可穿插在章节之间。操作可撤销，保存前只在草稿。
- 项目库仅挂起当前项目，使用“返回《项目名》”继续；“文件 → 关闭当前项目”才真正关闭。示例关闭不保留，正式保存需另存为。
- 点击左上“策问”进入全项目问答。选择或填写就是已回答，空白题暂缓；题目有问题可用独立按钮反馈。切题自动保留本机回答。
- 本轮汇总自动收集回答，无需逐题勾选；末尾点击“复制开场白，请 LLM 分析”直接复制，显示实际保存版本和题数，也可预览编辑。将开场白发给 LLM；没有 MCP 且可执行本机命令时可用现有 CLI，无需先重启 Codex。模型先分析，再询问你是否开始下一轮并等待答复。
- 开始下一轮与采纳文档提案分别确认。MCP 心跳不等于模型已收消息；本软件不自动唤醒任意模型，不代答、不自动批准提案。
- 官方发行来源见下载附件 SOURCE.json；本机安装身份另见 LOCAL_BUILD.json。关于页、源码标签和下载版本应一致。

## 启动

连接区按 MCP 会话显示在线数量，同类会话合并为一张卡片；一个 Codex 程序可能建立多个会话。顶栏通道连接与当前项目访问分别提示，尚未访问项目仍可显示已连接。桌面快捷方式升级后，已配置的 MCP 启动入口需由客户端切换至本版路径并重新连接。

本机 Codex 通过 `App/Current` 固定安装入口接入。Current 与桌面快捷方式指向同一安装版；升级安装时同步切换这个入口。协作 Skill、协议和使用说明均从 Current 的安装文件读取，游戏资料仍在用户自己的项目目录。已运行的 MCP 需要重新连接才能加载新版。

完整解压后运行同目录的 `策问 Designform.exe`。无需安装 Node，也不用填写模型密钥。启动默认进入分页项目库。新建项目先描述设想、选择可选起步结构、编辑开场白与目录，再确认创建。示例可直接临时编辑；保存时另存为，关闭不保留。

桌面菜单“文件 → 在浏览器打开”打开同一项目服务。浏览器使用期间保持策问运行。端口占用会另选空闲端口，重启优先复用上次端口。

右上角太阳 / 月亮按钮一键切换深浅主题并保留偏好。桌面外框、菜单、表单和托盘随主题变化；“文件 → 收起到系统托盘”可隐藏窗口，点击托盘图标恢复。关闭主窗口会退出软件。“策问”采用完整中文字标；点击进入当前文档问答，项目库使用独立菜单入口。

星图总览以游戏总纲为中心，系统分层保持平面阅读。策划案正文中的下划线词语可悬停预览、点击跳转；“返回上一处”回到之前的阅读位置。必要关系依据收在文末，点击可展开。新版虚构示例演示这种写法；已有项目正文和历史不会被自动改写。

0.7.1 的系统分层按分类连续排列，文档的小节紧跟文档、子分类缩进；单独归类的小节显示在对应分类下。总览先显示归属线，点击节点再显示相关的跨系统连线。左键拖动平移，二维右键拖动框选、三维右键拖动旋转，空白滚轮缩放；横向模式沿分组从左向右阅读。旧版分层坐标会重新排布，新版的横纵摆放分别记忆；需要恢复整齐排列时点击“自动排布”。

顶部应用栏提供项目库、LLM 连接和主题切换。左栏只放当前项目、搜索及分层文档目录；点击文档前的箭头展开规则。系统筛选和阅读记录默认收起，目录占用余下高度，可独立滚动。窄窗口通过左上角目录按钮打开抽屉。

星图或分层中点击空白画布会取消选择、收起右侧详情，保留当前视角和筛选。拖动旋转、平移和缩放不会触发取消。关系分析保留焦点，通过返回按钮退出。

0.2.3 中，打开右侧详情会让星图和底部工具条平滑移到剩余区域的中心，关闭后回位；旋转角度和缩放不会被重置。验收步骤见 `resources/integration/protocol/VIEWPORT_REVIEW_0.2.3.md`。

0.3.0 中，中央总纲使用与普通节点相同的单行文字标签，以金色区分；浅色主题使用更深的金棕色。顶部“策图标＋问”与英文名改为水平对齐，窄窗口隐藏辅助英文名。详见 `resources/integration/protocol/LABEL_REVIEW_0.2.4.md`。

## 0.4 创作入口

项目中心可以组合类型、规模、玩法与自定义条件，预览和修改开场白，复制给 LLM 或手工建立项目。八类场景覆盖构思、导入、接入、写作、问询、审阅、回答迭代与交接；复制不会自动连接模型。

星图右键或“＋ 新建”直接进入写作，默认只显示标题和正文。设计分类可选常见类型并自定义、改名、改色、排序；未完成的新稿可继续恢复。高级源码和关系操作按需展开。第一次保存才创建正式 Markdown，临时图片与正文一起进入版本。

星尘随有效 DD 数量变化，总纲光晕收紧并轻微呼吸，浅色分类使用更深的颜色。

## 0.5.1 项目与写作入口

项目库用于查看、打开和复制已有项目；“新建项目”进入独立的游戏设想页。类型、目标、玩法和平台可多选并补充自定义内容，开发资源和单次体验时长保持单选。开场白可预览、改写并复制；软件根据实际 MCP 心跳给出已有工具核对或接入步骤，复制本身不代表已连接。已有项目会带入项目身份，尚未创建项目时只核对工具连通。

写作页将保存、正文工具和文档属性分区显示；在“更多 → 文档属性与别名”登记缩写与别名，输入标题或别名后选择候选即可插入 Markdown 链接。图片可拖动下方手柄缩放，保存并重开后保留尺寸。有锚点的规则章节可单独移入分类，章节仍保留与原文档的目录关系。分类删除时需将引用该分类的文档与章节一并迁移；正式修改仍由保存版本提交。写作区和图谱操作的改动与待验收项目见 `resources/integration/protocol/EDITING_REVIEW_0.5.1.md`。

## 0.5 正文与关系编辑

正文默认使用块编辑器，输入 `/` 添加段落、列表、图片、表格；拖动块左侧把手调整次序。Ctrl+K 或输入 `[[` 按标题选择 DD，插入真实 Markdown 链接；“关系与引用”查看出向联系和反向引用。功能字段仍收在源码与文末。无法无损转换的特殊 Markdown 会保留源码编辑。

3D 拖动文档只调整摆放，拖动分类可移动星团；总纲固定在中央。右键可以固定或解除固定节点，固定节点不被邻居挤开。2D 可把 DD 拖到分类标题改变归属；选中节点的方形端口修改分类，圆形端口建立虚线关联。选择手工关系后可拖动两端改接，拖到空白断开。正文引用通过“修改正文引用”选择具体原句处理，保留文字。

二维普通关联支持插线选择；“晃动断开普通关联”默认关闭，开启后只有连续左右晃动再松手才断开普通手工关联，不删除正文链接或分类。拖拽过程中按 Esc、窗口失焦会取消。结构变更先保留为私人草稿；Ctrl+S 或“保存结构版本”才记录正式版本。纯摆放不生成版本。

Ctrl+Z / Ctrl+Y 撤销重做；正文的 Ctrl+C/X/V/A 使用文本语义，画布上 Shift+点击可多选；二维空白拖动框选，三维按 Shift 后空白拖动框选，Ctrl+C/V 创建独立 DD 副本，Ctrl+X 后在目标分类 Ctrl+V 移动归属。画布复制粘贴暂限当前项目。Ctrl+F 按当前焦点查找；桌面编辑菜单沿用同一操作。历史只读。

首轮验收重点与尚未覆盖的组合见 `resources/integration/protocol/EDITING_REVIEW_0.5.0.md`。

## 文档与版本

每个项目都有独立目录，默认放在“文档/策问工作区”，新建时可选择其他父目录。

- `PROJECT.md`：项目身份。
- `docs/gdd/`、`docs/dd/`：当前策划 Markdown。
- `docs/questions/`：问题、用户原话、模型解释、决定及落实情况。
- `docs/assets/`：附件。
- `versions/`：每次正式保存的完整公开快照、校验和、版本说明与命名基线。
- `.cewen/`：分组、标签、批注、私人笔记、草稿、提案和布局；不是策划正文。

编辑器自动保留草稿，点击“保存版本”才写入正式文档。外部编辑器也可修改当前 Markdown；策问同步观察到的稳定内容。历史快照请不要直接改写，恢复旧版会创建新版本。

“整理”保存工作分组、标签和批注；“版本”查看、比较和播放策划演进；“交换”先预检导入，或导出当前稿、历史包、完整备份。每日首次稳定读取创建本机恢复点并轮换最近 7 份。

## 与任意 LLM 协作

把项目内的 `PROJECT.md`、`docs/README.md` 和本轮相关文档交给模型即可开始。模型生成问询包，用户在策问回答；模型读取回答后生成提案，用户查看差异并采纳。推荐方案不会代替用户作答。

完整接入说明在 `resources/integration/protocol/INTEGRATION.md`，其中包含 CLI、MCP、Schema 和错误处理约定。独立 Skill 在 `resources/integration/skills/cewen-collaborate/`。命令行入口是 `策问CLI.cmd help`；MCP stdio 入口是 `策问MCP.cmd`，均使用内置运行时。

右上角连接区显示实际 MCP 通道状态，点击可查看客户端、模型、最近访问项目和活动时间，也可生成可直接发送给 LLM 的接入开场白。模型名可由客户端连接配置的 env 提供 `CEWEN_LLM_NAME`，或由明确知道自身型号的 LLM 调用 `cewen_identify`。未提供时明确显示未知，不猜测型号。正常关闭后变为断开，异常退出约 35 秒后判定断开，页面每 4 秒刷新一次。在线表示通道可用，不代表模型正在思考；文件或 CLI 协作不保持在线状态。

真实游戏接入应在游戏策划任务中单独进行：固定本包版本、只读来源、创建独立目标项目、先预检再确认。本发行包不包含真实游戏资料。

## 正文编辑、字体与载入

“文档视图”和“自由视图”都能直接单击正文编辑，文档属性在右侧。右上锁定按钮保护当前文档；解锁后可继续编辑。选中文字后，在浮动工具栏点击斜体或“文字样式”图标，选择本机字体、荧光笔、字体颜色及字体背景颜色；面板保留原选区，完成后继续输入。字体列表支持搜索和刷新，按本机已安装字体家族提供，不复制字体文件。文字样式随正文保存并在两种视图中显示。

分类、文档和总置顶区的长名称使用省略显示，纵向浏览保留，不出现左右滚动条。系统分层只将同层分类并列，各分类的文档依次向下或向右排列。打开项目时显示文件读取、分类准备、内容准备、界面显示进度；读取阶段可取消打开。

## 版本边界

点击左上「策问」进入全项目问题模式，不要求预选分类。选择、填写或反馈题目即自动记录，无需保存、提交或逐题复核；左上待答数实时减少。筛选为全部／待答／已答。等待前题时点击题名，回答后可返回原范围。轮次汇总列出所有历史轮，每轮收起，进入某轮再查看回答或直接复制开场白交给 LLM。已答题后续修改、追问使用新题、新轮，旧问答保留。模型讨论后等待你同意下一轮。返回阅读恢复原视图和目录。

文档视图与自由视图的输入光标按实际文字位置显示，颜色随主题，保持 2px 可见宽度；选区和中文输入法组合时使用原生光标，正文排版不变。

本版为本地单用户、线性版本工具。暂不提供云同步、多人权限、分支合并或自动更新。完整快照会随版本增长；大型图谱先显示系统和文档，按需展开规则。

Windows 包未代码签名。首版检查记录和已知限制见 `resources/integration/protocol/RELEASE_CHECKS.md`。第三方许可见 `resources/THIRD_PARTY_NOTICES.md` 与 `resources/dist/licenses/`。

0.2.1 的人工验收步骤见 `resources/integration/protocol/READING_REVIEW_0.2.1.md`；自然文字关联与文末索引的写作说明见随附 Skill 的 `references/WRITING.md`。

## 0.6 统一设计工作台

点击左上项目身份打开图标、名称、简介和备注设置；顶部“项目库”仍负责项目切换。目录提供文档、收藏、最近三个分页与分类分栏；F2 和条目菜单可改名、设置别名、颜色、分类与顺序。分类颜色同时映射星图与系统分层。

文档工具栏提供“正文 / 排版 / 注释”。排版改变同一文档的块位置、尺寸和层级，明确的阅读前后移才改变 Markdown 顺序。标题箭头折叠整章。纸张可选方格、横线、点阵或素纸。注释有荧光笔、画笔、箭头、文字和贴图；“项目共享”随保存版本提交，“我的私注”只写本机工作区。

“插入”可添加互动对白和设计色板。对白在文档里可点击预演，独立编辑页面中编排节点与分支。色板可读取本机图片，在本机提取全图/区域颜色，也可取单点色；设计色与原图候选分开。原图作为文档附件保存。

写作底部统计当前草稿；主工作台“统计”汇总已保存版本并导出 CSV。公开布局和注释在 docs/layouts 与 docs/annotations，不复制正文，随文档共同进入版本、备份、导出和恢复。

## 本轮协作流程更新（2026-09-29）

新建第二步左侧组合设想、右侧查看并编辑完整开场白；“展开预览”把开场白扩展到整块内容区，“返回组合”恢复两栏。预设方向不变，组合明确列出会加入的内容；类型与目标、内容与载体、制作条件可以切换填写。选项变化不会覆盖手改开场白，主动“重新生成”才替换。标题、右上角关闭和底部操作保持可见。

“示例与新手教程”用卡片选择学习内容，选中后再打开，仍为临时编辑。目录中展开文档后点击章节，文档视图会滚动到标题，自由视图会平移画布到对应章节；折叠父章节会自动展开，并短暂强调落点。

新建项目先选择游戏、叙事与世界观、剧本、微电影、综合创作或空白。前五类可以多选和补充设想，随后确定名称与位置，并获得绑定真实项目的可编辑开场白。默认不预置空文档数量，交给模型根据复杂度拆分；空白模式直接人工编写。

普通创作由 MCP 任务自动备份、锁定、分段显示和完成保存。LLM 工作稿直接出现在正常目录和文档区，期间可以阅读，不能通过普通解锁按钮编辑。黄闪表示工作中，绿空心为连接待命，绿实心为保存完成，灰色未连接，红色为异常；详情可以定位、停止、重新校验恢复或撤销本任务。异常工作稿不会自动发布，个人未保存内容另存草稿供比较恢复。

GitHub Pages 使用独立本机接入环境：同意后缓存经校验的 ZIP，部署到授权项目 `.cewen/connector/`。首次由有本机权限的工具或用户解压到 `runtime` 子目录，再运行其中“启动接入.cmd”；网页不会自行执行本机程序。配对成功后统一经本机服务读写，断线不会自动退回浏览器写入。协议和详细验收边界见 `resources/integration/protocol/COLLABORATION_IMPLEMENTATION.md` 与 `PAGES_CONNECTOR.md`。
## 输入、浏览与快捷键

引用单击跳转，Alt+单击编辑引用文字。编号列表 Enter 继续、Shift+Enter 项内换行、空项 Enter 退出。段落样式、标题级别、文字格式与格式刷位于右侧工具区；右键插入按用途分类。

鼠标侧键和应用顶部左右箭头可返回/前进已浏览页面。浏览不会自动保存文档。文件或帮助菜单打开“快捷键与鼠标设置”，可自定义按键、交换/关闭侧键、设置右键拖动距离及主题动画。
