# 策问 Designform

百舸体系下的本地游戏策划与 LLM 协作工作台。应用 0.4.0，文档格式 1，接口协议 1。

当前实现独立项目、Markdown 编辑、公开版本、问询与提案审核。提供 GitHub Pages 网页版与 Windows 桌面版，共用业务规则和项目格式，不绑定模型厂商。网页版授权本机文件夹后直接读写，策划内容不上传。

## 使用入口

- [直接打开网页版](https://syurli.github.io/Designform/)：桌面 Chrome / Edge 选择本机文件夹即可使用。
- [下载 Windows 便携包](https://github.com/Syurli/Designform/releases/latest)：解压即可运行，包含 CLI / MCP。
- [双版本开发与发布](docs/双版本开发与发布.md)：文件权限、备份、两端切换及版本约定。

网页版虚构示例存于浏览器本机存储；正式项目必须选择磁盘文件夹。两端接续时关闭原端，再用另一端打开同一目录。

## 使用桌面发行包

解压 Windows 便携包，运行 `策问 Designform.exe`。项目中心可新建空白项目、基础 GDD，或复制完全虚构的“纸上远行”示例。

菜单“应用 → 在浏览器打开”打开同一个工作台。使用期间保持桌面程序运行；退出会停止其本地服务。默认项目父目录为用户文档目录下的 `策问工作区`，新建时可指定别处。端口占用时自动选择空闲端口。

```text
PROJECT.md             项目身份与说明
 docs/                 当前有效 Markdown
   README.md           任意 LLM 可直接阅读的格式说明
   gdd/  dd/           总纲与专项设计
   questions/          问题、用户原话、解释、决定
   assets/             相对路径附件
 versions/             完整公开快照、说明、清单与基线
 .cewen/               草稿、批注、分组、提案、布局和索引
```

用户与 LLM 读取公开文档即可理解策划，无需读取应用源码或 SQLite。

0.2.1 提供柔和雾灰蓝 / 深色星空主题，桌面外框、菜单和托盘一起切换；品牌组合为“策字图标 + 问”。3D 总览以总纲为中心，正文支持关联词悬停预览、章节跳转和阅读回退。功能性关系表后置折叠，LLM 写作规范随 Skill 一起交付。详见 [本轮优化与人工验收](docs/本轮优化与人工验收_0.2.1.md)。

0.2.2 将应用功能放到顶部，左栏专用于当前项目的搜索和文档目录；文档下可展开规则，筛选默认收起。星图和分层点击空白可取消选择并收起详情。右上角新增真实 MCP 连接状态、客户端与模型名称。详见 [主面板与连接状态](docs/主面板与连接状态_0.2.2.md)。

0.2.3 修正详情遮挡星图：右侧详情打开时，星图和分层平滑移到剩余区域的中心，关闭后回位，保留当前旋转及缩放。底部工具条同步跟随；关系分析继续使用独立卡片排版。见 [视角避让说明](docs/protocol/VIEWPORT_REVIEW_0.2.3.md)。

## 日常操作

0.4 提供游戏设想组装器与八类协作开场白；从星图右键直接新建，默认写标题与正文，文件头和路径按需查看。新稿可恢复，附件随首存一起进入版本。常见 DD 分类可选、自定义、改色、排序及迁移；银河星尘随 DD 数量变化，浅色使用更深的分类色。详细覆盖见 [0.4 验收记录](docs/protocol/AUTHORING_REVIEW_0.4.0.md)。

- 创建与编辑：手工建立 GDD/DD/问题。编辑器提供预览、格式按钮、草稿恢复、章节排序、标题/归属、关系与图片；正式保存产生版本。
- 阅读：星图与系统分层在同一画布切换；关系分析为次级页面。策划案与卡片读取相同文档。大型图谱先展示系统/文档，可筛选或展开规则。
- 整理：分组支持多重收纳、简单嵌套和排序；批注保留摘录、回复与处理状态；标签、标记、批量归档和阅读视图与正文分开。
- 版本：选择、播放、比较、历史阅读。条目/文档共用修订链；恢复整版或撤销旧批次都创建新版本。命名基线可改名或取消。
- 问询：单选、多选、自定义、暂缓、否定前提；推荐不会自动选中，改答追加原话。条件题需满足前题条件。
- 提案：查看差异、编辑候选、全部或部分采纳。问题与各 DD 落实记录同步更新；过期依赖、改写原话或不完整引用会被拒绝。
- 交换：目录或粘贴导入先预检，可跳过和编辑候选；按稳定身份去重，附件与链接一并迁移。导出当前稿、历史包或完整备份。
- 备份：每日首次稳定读取创建本机完整恢复点，轮换最近 7 份；手动导出不参与轮换。完整备份可明确选择是否携带个人记录。

## LLM 接入

桌面版先启动策问，再使用发行包顶层 `策问MCP.cmd` 或 `策问CLI.cmd help`。启动器使用应用内置运行时，无需另装 Node。MCP 为 stdio，配置见 [独立接入说明](docs/protocol/INTEGRATION.md)。

右上角连接区提供可复制的接入开场白与真实在线状态。模型名由 `CEWEN_LLM_NAME` 或 `cewen_identify` 明确提供；未知时显示“模型未提供”，不会由客户端名称推断。直接文件与 CLI 协作不显示为持续在线。

没有 MCP 时，使用项目 Markdown 和交换面板完成问询/提案闭环。接入包含 [Skill](integration/skills/cewen-collaborate/SKILL.md)、[文件格式](docs/protocol/PROJECT_FORMAT.md)、协议、Schema 与示例。

真实游戏接入独立于工具开发。本次只使用虚构与合成资料；战术巫师由用户在游戏策划任务中按 [独立接入流程](docs/策问_独立项目接入流程_20260922.md) 发起。

## 开发与构建

需要 Node.js 24、npm；依赖由 `package-lock.json` 固定。

```powershell
npm ci
npm run dev
npm run build
npm run build:runtime
npm run serve
npm run package:win
```

开发默认使用 `策问工作区/开发沙盒`，正式服务使用 `策问工作区`。`CEWEN_HOME` 可指定独立项目中心，`CEWEN_URL` 可让 CLI/MCP 指向指定回环服务。独立网页使用 npm run dev:web 或 npm run build:web；构建部署到 GitHub Pages 的 /Designform/ 路径。直接双击 HTML 不支持文件夹授权。

保留视觉基线：总览切换 1150 ms、分析进入/返回 520 ms、内部焦点 360 ms。版本演进 850 ms，分析内 360 ms；系统减少动态效果时直接到达终点。

## 交付与边界

本地单用户首版，采用线性完整快照；暂不包含云同步、多人权限、历史分支合并、自动调用模型或自动更新。导入/备份单包上限 150 MB、10000 文件。撤销与后续内容重叠时需要手工合并。

验收采用类型检查、生产构建、人工浏览器、文件往返和协议操作，没有执行自动化测试套件。实际覆盖和未覆盖项见 [首版验收记录](docs/首版验收记录_20260922.md)。Windows 包尚未代码签名，签名和更新属后续范围。
