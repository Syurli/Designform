# 策问 0.2.2 · 主面板与连接状态

本轮调整应用布局、空白取消选择和 LLM 连接显示。项目 Markdown、公开版本以及真实游戏接入流程保持独立。示例仍为完全虚构的“纸上远行”。

## 页面分区

| 位置 | 内容 |
|---|---|
| 顶部应用栏 | 策问品牌、项目库、LLM 名称和连接状态、主题切换 |
| 左侧项目目录 | 当前项目、搜索、可折叠系统筛选、阅读记录、文档与规则目录 |
| 主体上方 | 知识空间 / 策划案 / 卡片库；新建、编辑、版本、整理、问询、交换 |
| 主体右侧 | 选中条目或关系的详情；取消选择后收起 |

左栏从混合功能菜单改为项目目录。系统筛选默认收起，GDD 优先显示；每份 DD 可展开自己的规则，选中规则会展开所在文档。目录独立滚动，尽量占用可用高度。窗口变窄时，目录由左上角按钮呼出，可点击遮罩或关闭按钮收起。

星图与分层的切换靠近标题，选中条目后仍可直接使用。关系分析为卡片留出详情以外的宽度，按列均匀排布，避免较窄窗口内卡片相互覆盖。分析进入和内部切换时长沿用原版本。

## 取消选择

星图、系统分层中点击空白画布，会清除选中条目、关系及“只看相关”，收起详情，保留当前系统筛选、搜索和视角。只有主指针单击才触发；拖动超过 5 像素后即使回到起点，也不会误判为空白点击。右键、多指操作、取消的触摸不触发。

关系分析保留当前焦点，仍通过“返回星图总览 / 返回系统分层”退出。空白取消不会改写文档或产生公开版本。

## LLM 名称与状态

右上角常驻连接摘要，点击打开详情：客户端名称和版本、模型名称及来源、最近访问项目、最近活动。支持同时列出多个连接；优先展示访问当前项目的在线连接。

- 已连接：适配器完成 MCP 初始化，并持续收到心跳。
- 模型未提供：客户端连通，但没有明确提供型号，界面显示客户端名并提示未知。
- 已断开：客户端关闭，或 35 秒未收到心跳；断开记录临时保留。
- 状态暂不可用：工作台暂时无法读取服务，不据此假定客户端已断开。

模型名通过连接配置的 `CEWEN_LLM_NAME` 或模型调用 `cewen_identify` 提供，详情标明配置或自报来源。策问不猜测模型，不把连接状态当作模型正在思考，也不把文件 / CLI 访问显示为持续在线。接入配置可从连接详情复制，随后替换安装目录。

心跳每 10 秒发送，页面每 4 秒刷新。状态仅存在于本地服务内存，未写入公开文档、历史版本或私人笔记。未修改本机 LLM 客户端配置，真实客户端接入由用户按说明完成。

## 本轮检查与人工验收

已执行类型检查、生产构建、运行时构建，以及浏览器和手工 MCP 协议操作；没有执行自动化测试套件。

已观察：空白点击后条目取消、详情收起；层级目录及系统筛选可操作；选中时可切换分层与星图；关系分析有独立可读区域；深浅主题覆盖新增界面；MCP 初始化、未知模型、项目活动、正常断开显示符合实际。协议检查使用明确标注“非 LLM”的临时客户端，不能当作真实模型接入验收。

建议人工重点检查：

1. 选中星点，旋转视图，再点击空白：选择取消，保留旋转后的方向。拖动后松手不应取消。
2. 展开多个 DD、滚动目录、使用搜索与系统筛选，确认目录空间足够。
3. 在 3D、分层、分析、正文和卡片之间切换，检查常用按钮位置与阅读宽度。
4. 通过实际 LLM 客户端接入，确认其客户端名和明确提供的模型名；关闭后检查断开状态。
5. 在桌面包中切换深浅主题，检查外框、菜单、连接面板和窄窗口目录。

本轮原生桌面操作、不同模型客户端、异常终止后的超时，以及多客户端同时接入留给人工验收。浏览器检查不等同于这些项目已全部通过。

更新时先退出旧版桌面程序，再运行新便携包；无需移动独立项目文档。
