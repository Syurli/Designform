## 保持的设计

总览切换 1150 ms，分析进入/返回 520 ms，内部焦点 360 ms。版本生长沿用同画布与稳定身份：新增展开、离开收拢后释放，避免整屏清空。不增加关系矩阵或第三个总览模式。

当前稿在 docs，公开完整历史在 versions，编辑器工作记录在 .cewen。模型只需要读取项目说明与 Markdown。开发全部使用虚构资料，没有访问真实游戏目录。

## 实际修正

- 同文件并写：保留草稿、磁盘稿、编辑前原稿，比较并更新基准后保存。
- 部分采纳：原提案不变，逐文件记录实际采纳哈希；改答使旧提案需要重新核对。
- 中断恢复：校验日志、备份和当前指纹，第三种内容不会被回写覆盖。
- 导入审核：改变勾选或候选即禁用应用，必须重新预检。
- 快速切版：稳定节点保留位置并恢复交互状态，旧节点动画完成后释放。
- 阅读与重连：过滤/标签/静止状态持久化，宿主重启优先复用上次端口。
- 外部批次：完成回执先落盘，响应丢失后重试不会重复封版。
- 损坏锁：保留现场并给出中文恢复说明，不让 JSON 解析错误遮蔽原操作结果。
- Electron 启动：修正 ESM 顶层等待 ready 的互锁，窗口不依赖显卡首帧才显示。
- 备份范围：手动完整包仅在选择个人记录后携带私人批注、草稿和阅读布局。

## 0.2.1 阅读与星系优化

按最新要求降低浅色主题大面积亮度，统一桌面外框配色；品牌区显示“策图标 + 问”，项目入口恢复文档图标。GDD 根据明确类型成为星系核心，系统沿旋臂聚类，背景星尘不生成关系。保留原切换时长与分析卡片展开方式。

增加自然文字链接预览、同名唯一目标提示、规则锚点定位及阅读回退。显式 Markdown 链接进入知识关系并去重；自动提示不写入正式关系。必要语义索引采用文末“来源身份”列，旧表仍可阅读。管理界面对派生引用指向正文编辑，禁止通过反转接口把它误写成关系表。

仅更新软件自带虚构模板和新项目说明；未迁移用户已创建项目。Skill 增加阅读优先规范与完整示例，随发行包提供。类型检查和构建通过，浏览器实际确认新模板、品牌、两种配色、中央总纲与正文链接显示。最终主观效果由用户人工验收，详见本轮验收文档。

## 0.2.2 主面板与连接状态

应用功能移至独立顶部栏，左侧专用于当前项目目录；搜索、折叠系统筛选与可展开 DD/规则目录保留更多阅读高度。项目操作与视图切换位于主体顶部。未选择时收起详情；星图与分层点击空白可取消选择，最大拖动距离和主指针判断避免旋转时误取消，相机不主动重置。分析卡片按等宽列排布，详情不覆盖卡片内容。

增加仅驻留内存的 MCP 连接表、初始化后心跳、主动断开与超时判定。顶部连接摘要与详情区显示客户端、模型、名称来源、最近访问项目及活动；新增 cewen_identify，MCP 工具总数为 12。名称未知时明确标注，不将浏览器、文件或 CLI 访问伪装为 LLM 连接。未修改用户模型客户端配置。

类型检查、生产和运行时构建通过；浏览器与手工协议检查确认布局、空白取消、两种主题、未知模型、项目活动和断开状态。未执行自动化测试套件。桌面窗口、真实 LLM、多客户端和异常退出超时留待人工检查，详见 [0.2.2 验收说明](主面板与连接状态_0.2.2.md)。
