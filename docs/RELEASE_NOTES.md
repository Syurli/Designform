# 策问 Designform 0.8.0

0.8.0 加入正式的新手教程框架。首次打开已有项目时会启动“认识策问”导览，覆盖项目入口、文档目录、搜索、知识空间、写作、整理、版本、问询、交换、LLM 协作、MCP 连接与外部文件刷新。教程支持上一步、下一步、**跳过**与**快进**，完成或跳过后不会反复打扰；顶部“？”可以随时重新运行完整导览或专题教程。

教程展示层采用 Driver.js，策问自己维护教程定义、进度和业务语义。DOM 高亮没有写死在各组件的 CSS 层级，而使用稳定的 `data-tutorial` 目标。新增 Babylon 教程适配契约，为未来基于 Babylon.js 的游戏保留 `mesh:` 与 `event:` 类型的 3D 目标和游戏事件扩展入口。

- 完整“认识策问”导览覆盖主要工作台模块。
- 提供“知识空间”“策划写作”“LLM 协作”三个专题教程。
- 可从帮助菜单查看教程状态、重新开始或重置记录。
- 教程进度只保存在本机偏好，不进入游戏策划 Markdown、版本或私人项目工作区。
- Driver.js 只负责 spotlight / popover；未来 Babylon.js 项目可以复用 TutorialDefinition / Progress，替换展示适配器。
- Driver.js 固定版本并随应用打包，不依赖运行时 CDN。

同时包含上一轮 MCP 协作能力完善：当前状态、分段文档读取、项目级提案状态、图片附件、基线、备份状态及恢复/撤销计划均有受控工具入口，继续保留用户作答、提案采纳和正式恢复的人工作业边界。

发布检查以仓库 GitHub Actions 的类型检查、桌面/网页/运行时构建与 Windows x64 打包结果为准。Windows 用户下载下方 ZIP，完整解压后运行“策问 Designform.exe”；原项目继续使用原来的独立项目目录。校验文件为 SHA256SUMS.txt。

网页版入口：[策问 Designform](https://syurli.github.io/Designform/)。
