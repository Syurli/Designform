# 策问 Designform 0.9.0-rc.2 · 手动验收版

本版将预设改为创作起点：游戏、剧本、微电影、世界观与空白项目都可组合相同模块，不按项目类型限制地图、角色、分镜或配音。

## 本轮可验收内容

- 模块源、共享引用、独立复制及跨类型引用检查；同一地图被战斗 DD、剧情线与镜头共同使用，各使用层独立。
- 地图画布支持点位、路线、区域、拖动、缩放、撤销／重做与显式保存。删除或改写来源时，问题锚点明确提示人工重定位，不猜相似段落。
- Quest 目标、轮次、原话、用户决定与提案落实分开；集中及文档内问题筛选、续轮请求、按修订游标增量接续。
- 场次、角色造型、声音档案、台词、镜头与连续画面；审阅／观影／台词排演，独立跨镜音频，按需媒体加载、时长调整、按键录制节奏、暂停提问及自包含 HTML 排演包。
- 按场次／序列展开图片与配音任务，筛选缺失或变更、选择任务、编辑提示词；批量回导预检、人工映射、候选选择与采用分离。
- 本机 ComfyUI 图片适配器具有参考图明确映射与上传、负向提示词映射、状态刷新、安全取消和不确定提交保护。真实模型／显存／工作流仍由用户在本机验收；配音支持通用任务包与音频回导，不绑定 TTS 厂商。
- 六类起步预设、虚构综合示例与演示版本链；九类专题导览及九类独立操作练习。跳过、部分完成、暂停和完成分别保存，练习必须在独立副本内收到实际操作回执。
- MCP 32 工具、模块资源与续轮 Prompt；万类提供意图交接与返回预检，不声称已完成真实三维联调。
- 格式 2 不可变媒体地址及历史引用；旧格式在独立副本升级，保留原文件和旧历史。

## 验证与边界

类型与双端构建、独立虚构项目事务/迁移、真实 stdio MCP、ComfyUI 协议仿真、教程编排及合成大索引检查均有专项脚本。逐项结果见 `docs/protocol/QA_0.9.0_RC2.md` 和 GitHub Checks。浏览器实机、Windows 原生输入、真实 ComfyUI 模型、真实万类交接及长期大型媒体库使用仍需用户验收。

本版不包含三维导演台、完整剪辑台、MP4 编码导出、任意宿主自动唤醒模型、云端同步或默认读取私人资料。

Windows：下载 ZIP，完整解压运行“策问 Designform.exe”。核对 `SHA256SUMS.txt` 与 `SOURCE.json`。先使用虚构示例或项目副本，不用未备份的正式资料测试迁移。Pages 与 Windows 产物由相同的固定源码提交产生；已发布标签与附件不得覆盖。
