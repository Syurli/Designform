# 策问 Designform 0.9.4.1

等待前题的提示现在显示题名，点击即可跳转，填写后可返回原题。筛选简化为“全部／待答／已答”，保存与复核状态直接显示在题目旁。

## 更新

- 前题链接支持跨分类、来源和筛选定位；汇总中也能直接打开前题。
- 返回原题或原汇总时恢复搜索、筛选、来源和归档开关，切换前自动保留草稿。
- 同轮前题回答后可继续后题；跨轮需在前题所在轮次汇总保存，避免隐式保存其他轮回答。
- 删除“本机回答”和“题目更新”独立筛选；草稿显示“已答 · 待保存”，变化后的旧回答显示“需复核”并回到待答。
- 修正目录跨轮条件判断，待答计数与筛选使用同一规则。
- 保留 0.9.4 的项目锁恢复、性能优化、作答简化与低 token 分析交接。

## 使用

完整解压 Designform-0.9.4.1-Windows-x64.zip，运行“策问 Designform.exe”。已有项目直接打开原目录，回答与历史继续保留。网页与 Windows 使用同一 main 源码及 v0.9.4.1 标签。

附件包含 ZIP、SHA256SUMS.txt 与 SOURCE.json，记录校验值和源码提交。项目格式继续支持 1 / 2，接口协议为 1。

## 验证

类型检查、两端构建与运行时打包通过；隔离虚构项目人工核对前题跳转、草稿保留、返回恢复、条件解锁、汇总保存与复核筛选。默认未运行自动化测试套件。详见 [检查记录](https://github.com/Syurli/Designform/blob/v0.9.4.1/docs/protocol/QA_0.9.4.1.md)。
