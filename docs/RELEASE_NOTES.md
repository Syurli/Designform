# 策问 Designform 0.9.4

本版整合跨电脑项目打开修复、大项目性能和策问流程优化。网页与 Windows 便携包使用同一 main 源码及 v0.9.4 标签。

## 更新

- 修复从另一台电脑复制的项目被过期占用锁拦截；正在工作的项目仍保持互斥。
- 合入大项目刷新、Markdown 解析及目录缓存优化，减少空闲阅读时的卡顿。
- 作答区只保留题目、必要背景和回答；未指定来源摘录时不误报文档不存在，题目反馈改为独立按钮。
- 选择或填写即算回答，空白题暂缓。汇总取消逐题二次勾选与独立提交，末尾一键保存并复制分析开场白。
- 开场白改用短项目号、短版本号与读取引用，读取结果使用 Q/D 短号、正文按需获取。24 题实际开场白从 7,605 缩到 265 字符，减少 96.5%（字符比较）。
- 模型无需收发或核验逐题 hash；软件自动补全提案的正式路径、元数据和保存基准，简短回执不重复候选正文。
- 修复用户审核采纳提案误走模型直接写入保护分支的问题；保留用户原话、历史和相关文件冲突保护。

## 使用

完整解压 Designform-0.9.4-Windows-x64.zip，运行“策问 Designform.exe”。已有项目直接打开原目录；不需要迁移文档或重新作答。回到回答汇总重新复制开场白即可使用短号读取，旧 MCP 的同名工具可直接透传引用。

下载附件包含 ZIP、SHA256SUMS.txt 与 SOURCE.json，记录包校验值和源码提交。桌面与网页继续支持公开格式 1 / 2、接口协议 1。

## 验证

完成类型检查、桌面与网页生产构建、运行时打包；隔离虚构项目人工核对作答、短号读取、固定版本复读、候选审核、改答冲突、CLI 与 MCP。既有本机会话实际读取 24 题及按需正文，更新前后项目公开文本保持一致。默认未运行自动化测试套件；发布产物以 GitHub Actions 结果及附件来源记录核对。详见 [验收记录](https://github.com/Syurli/Designform/blob/v0.9.4/docs/protocol/QA_0.9.4.md)。
