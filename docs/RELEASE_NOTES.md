# 策问 Designform 0.6.0

统一设计工作台现支持同一 Markdown 文档内的正文、图片排版、互动对白、设计色板与共享注释。

- 雾纸/墨石主题、项目独立身份设置、分类与文档分栏目录、颜色与别名管理、内容统计。
- 项目面板可随时收起和展开并记忆；方格/横线/点阵底纹覆盖整个策划案面板，边缘柔和淡出。
- 图片缩放与文档排版、标题折叠、对白蓝图编辑与选项预览、图片主色提取和设计色板。
- 注释笔、荧光笔、箭头、文字和贴图；共享注释和私人笔记分开，公开布局与笔画跟随版本。
- 图谱拖动的局部阻尼跟随与相机过渡；3D 摆放和 2D 结构编辑各有明确作用。
- 新增分类整理、对白检查、共享注释汇总、色板比较和内容复盘的协作开场白。

两端构建、隔离虚构项目人工界面检查与公开伴随文件的版本链路检查已完成；不代表覆盖全部设备与复杂手势组合。范围见 `protocol/WORKSPACE_REVIEW_0.6.0.md`。真实游戏接入仍由用户在游戏项目对话中单独开展。

Windows 包仍为免安装便携版，尚未代码签名；旧项目文档位于独立工作区，升级应用不会主动改写它们。

# 策问 Designform 0.4.0 验收候选

- 项目目录使用系统或浏览器文件夹选择器，取消保留原位置。
- 设想组装器和八类协作开场白；手动创建和 LLM 协作使用同一份设想。
- 正文优先的写作工作台，可恢复新稿，临时附件同批保存，元数据默认隐藏。
- 常用设计分类、自定义、颜色、排序、删除后成员迁移；星图右键创建与整理。
- DD 驱动星尘规模、细微流动与核心呼吸；浅色分类色统一加深。
- 更新公开文件规范及协作 Skill，真实游戏接入仍为独立验收流程。
- 桌面标题栏不再重复显示品牌，上方仅保留应用菜单与窗口控制。
- MCP 入口直接复制专用接入开场白，预览按需展开，不再要求选择策划任务。

两种发行共用源码；本轮为功能分支验收候选，稳定 Pages 与正式发布待人工验收后更新。验证范围见 `protocol/AUTHORING_REVIEW_0.4.0.md`。

# 策问 Designform 0.3.0

首次发布共用源码的独立网页版和 Windows 桌面版。

- [直接打开网页版](https://syurli.github.io/Designform/)：桌面 Chrome / Edge 授权本机文件夹后，即可创建、阅读和编辑策划案，文档不上传。
- Windows 用户下载 `Designform-0.3.0-Windows-x64.zip`，解压运行 `策问 Designform.exe`。包内提供 CLI、MCP 和独立协作说明。
- 两端共用 Markdown、历史快照、问询与 JSON 整理记录。保留深浅主题、星图、系统分层、关系分析、策划案及卡片视图。
- 旧 SQLite 整理记录首次只读迁移，原文件保留；请统一升级两端，不同时使用 0.2.x 修改整理记录。

同一项目一次使用一个策问写入端。网页试用示例和自动恢复点保存在浏览器本机存储，需长期保留时导出到磁盘；正式项目始终保存在用户授权目录。网页版采用文件/交换包协作，实时 MCP 使用桌面版。

Windows 包暂未代码签名，没有自动更新。详细边界与发布约定见仓库 [双版本开发与发布](https://github.com/Syurli/Designform/blob/main/docs/双版本开发与发布.md)。
