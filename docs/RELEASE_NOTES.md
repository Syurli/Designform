# 策问 Designform 0.9.3

本版整合 0.9.2 后的文档编辑、创作流程、目录、项目策问和 LLM 协作更新，作为正式版本发布。Pages 与 Windows ZIP 使用同一固定提交及 v0.9.3 标签。

## 本轮更新

- 引用文字优先跳转，Alt+单击编辑；末尾空格继续普通正文，链接支持折行。
- 两种视图统一编号、回车和项内换行，修复首行错位及连续 br 显示。
- 紧凑段落/标题/文字/格式刷工具区；插入菜单按五类用途组织；右键框选与单击菜单互斥。
- 归档过滤覆盖目录及卡片，浏览历史支持顶部箭头、Alt+Left/Right、鼠标侧键；设置提供快捷键、侧键、拖动距离与主题过渡配置。
- 新建保留六种创作方向，按方向优化辅助拼装，提供大面积可编辑开场白；示例学习卡片、固定弹窗操作和双视图章节定位。
- 原位正文编辑、无限深分类、收藏与总置顶、分页卡片、项目级逐题策问与分析交接。
- MCP 同类会话合并，连接与项目访问分别提示；受控任务备份、文档锁、分段工作稿及完成保存；Pages 独立本机接入包。
- 关于页显示作者李仕林、默认浏览器链接及 MIT 全文，Windows ZIP 附带 LICENSE。

## 下载与检查

完整解压 Designform-0.9.3-Windows-x64.zip，运行“策问 Designform.exe”。SHA256SUMS.txt 与 SOURCE.json 记录包摘要及源码提交；旧版项目可从新安装打开，软件不自动升级用户项目格式。

本机类型检查、双端生产构建、运行时及 Windows 打包通过。虚构项目人工检查覆盖引用、归档、列表、段落转换、分类子菜单、改键保存与关于页。未运行自动化测试套件。实体侧键、原生输入法、真实模型/ComfyUI 与长期大型资料库仍需实机验收。详见 [0.9.3 检查记录](protocol/QA_0.9.3.md)。

作者：李仕林。自有源码采用 MIT，允许使用、修改及商用；分发副本或主要部分时保留版权声明和许可文本。用户内容版权及第三方许可各自保留。

# 策问 Designform 0.9.2 · 文档工作台验收版

保留原主面板与星空／分类分层／思维导图／卡片关系预览；文档画布嵌入原策划案区域，分类颜色同源。桌面菜单合并为一条窗口顶栏。

本版按 V2.1 方案将工作中心统一为基础文档自由画布。启动项目库支持分页、时间、收藏、排序和二次确认删除；一体化新建向导把创作设想、可选起步结构、LLM 开场白与工程创建串在一起。

角色卡、地图卡和道具卡是普通文档预设，用户可创建并管理自己的组合。文档树、标签页和属性栏提供日常编辑；通用模块在文内插入，问策、排演和生产从当前文档进入。右键及可见菜单使用统一顶层浮层。

示例打开后可在相同工作台编辑和播放，所有编辑仅存本次内存会话。保存时另存为独立项目；取消不落盘，重开恢复原始示例。保存当前文档、保存全部及另存为的边界分别明确；候选提案仍需人工审核。

版本号为 0.9.2，但本次仍发布为 prerelease 供用户验收。原生输入法、真实第三方模型、文件夹授权和长期使用结果不作推定。详见 [0.9.2 状态](tasks/STATUS_0.9.2.md) 与 [验证记录](protocol/QA_0.9.2.md)。

# 策问 Designform 0.9.0-rc.3 · 手动验收版

本轮将基础与跨领域示例集中到“浏览示例”：选择和阅读不会创建项目或文件，只有明确点击创建独立练习副本才写入本地。正式项目的新建向导中的预设只给空白起步结构。示例文档按共享世界、故事与规则、影像表达、协作与制作建立父子分类；桌面外框“应用 → 关于策问”显示版本、作者与仓库。

本版将预设改为创作起点：游戏、剧本、微电影、世界观与空白项目都可组合相同模块，不按项目类型限制地图、角色、分镜或配音。

## 本轮可验收内容

- 模块源、共享引用、独立复制及跨类型引用检查；同一地图被战斗 DD、剧情线与镜头共同使用，各使用层独立。
- 地图画布支持点位、路线、区域、拖动、缩放、撤销／重做与显式保存。删除或改写来源时，问题锚点明确提示人工重定位，不猜相似段落。
- Quest 目标、轮次、原话、用户决定与提案落实分开；集中及文档内问题筛选、续轮请求、按修订游标增量接续。
- 场次、角色造型、声音档案、台词、镜头与连续画面；审阅／观影／台词排演，独立跨镜音频，按需媒体加载、时长调整、按键录制节奏、暂停提问及自包含 HTML 排演包。
- 按场次／序列展开图片与配音任务，筛选缺失或变更、选择任务、编辑提示词；批量回导预检、人工映射、候选选择与采用分离。
- 本机 ComfyUI 图片适配器具有参考图明确映射与上传、负向提示词映射、状态刷新、安全取消和不确定提交保护。真实模型／显存／工作流仍由用户在本机验收；配音支持通用任务包与音频回导，不绑定 TTS 厂商。
- 六类起步预设、虚构综合示例与演示版本链；九类专题导览及九类独立操作练习。跳过、部分完成、暂停和完成分别保存，练习必须在独立副本内收到实际操作回执。
- MCP 32 工具、模块资源与续轮 Prompt；万类提供意图交接与返回预检，不声称已完成真实三维联调。
- 格式 2 不可变媒体地址及历史引用；旧格式在独立副本升级，保留原文件和旧历史。

## 验证与边界

rc.3 本地已通过 Node 24 双端构建、四项 0.9 专项检查、只读示例库真实 HTTP 浏览器流程及打包桌面启动、版本信息和虚构排演检查。本轮提交的 GitHub Checks 将单独记录；逐项结果见 `docs/protocol/QA_0.9.0_RC3.md`。浏览器文件夹授权往返、原生 Windows 输入法与系统目录选择器、真实 ComfyUI 模型、真实万类交接及长期大型媒体库使用仍需用户验收。

本版不包含三维导演台、完整剪辑台、MP4 编码导出、任意宿主自动唤醒模型、云端同步或默认读取私人资料。

Windows：下载 ZIP，完整解压运行“策问 Designform.exe”。核对 `SHA256SUMS.txt` 与 `SOURCE.json`。先使用虚构示例或项目副本，不用未备份的正式资料测试迁移。Pages 与 Windows 产物由相同的固定源码提交产生；已发布标签与附件不得覆盖。
