# 策问 Designform 0.7.0

本轮整理多级项目目录，并把关系分析融入新增的设计脑图。

- 项目面板展开时只显示内部收起按钮，收起后显示外部展开入口。
- 总纲成为固定根文档；基础示例和新建示例不再将总纲归入体验方向。
- 分类与子文档支持排序、归类和升降层级；手柄可直接拖动，条目长按后也可拖动。路径导航让四至五级目录保持相同宽度。
- 写作页新增文档目录，拖入正文可在落点插入文档名与可点击链接；保存后纳入正式版本。
- 星图、系统分层和设计脑图共用知识空间；脑图点击节点进入关系聚焦。分层、脑图支持横向和竖向排列，保留连续转场。
- 修复含知识锚点的正文编辑器反复更新 DOM 导致卡顿，以及部分转场缺少节点坐标的问题。
- 更新公开层级规范与随包协作 Skill；软件源码和真实游戏接入继续隔离。

已通过类型检查、两端生产构建和隔离虚构项目的人工界面检查。具体范围见 protocol/WORKSPACE_REVIEW_0.7.0.md；尚待用户亲手验收。Windows 仍使用便携 ZIP，解压运行即可。
