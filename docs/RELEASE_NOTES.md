# 策问 Designform 0.7.1

系统分层恢复按分类分栏阅读，文档和小节在所属分支内连续排列，支持子分类缩进和横向阅读。统一标签位置，归属线沿留白走折线；选中节点才显示跨系统关联，减少总览中的交叉线。

旧版分层缓存不再覆盖新排布。筛选和公开层级变化后按当前内容重新组织，星图、设计脑图、正文及历史格式保持原有行为。

- 总纲统领顶层分类，同一文档及其小节连续阅读，子分类用缩进区分。
- 长分支可平移或缩放阅读，首屏不再为了容纳全部深层节点而过度缩小。
- 旧版分层坐标自动重新排布，新版横纵布局分别记忆；“自动排布”支持撤销。

类型检查、桌面及网页生产构建、Windows x64 便携包构建已通过；人工检查覆盖基础示例、五层目录、横竖切换、缩放与关联筛选。按工程约定未运行自动化测试套件。详细范围及已知边界见 [0.7.1 验收记录](https://github.com/Syurli/Designform/blob/v0.7.1/docs/protocol/WORKSPACE_REVIEW_0.7.1.md)。

Windows 用户下载下方 ZIP，完整解压后运行“策问 Designform.exe”；原项目仍使用原来的独立项目目录。校验文件为 SHA256SUMS.txt。网页版入口：[策问 Designform](https://syurli.github.io/Designform/)。
