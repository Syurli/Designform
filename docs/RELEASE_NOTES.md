# 策问 Designform 0.9.4.1

选择或填写即自动记录，答完一轮直接复制开场白交给 LLM 讨论。轮次汇总先显示所有历史轮，每轮收起；修改或追问进入新题、新轮。

## 更新

- 移除保存、提交、二次勾选和逐题复核，已答题直接编辑；改答仍保留历史原话。
- 来源、分析与前题更新不把已答题重新变为待答；正式已答题改变题意时使用新题与新轮。
- 汇总显示所有轮次，按轮收起，进入某轮查看问答并复制独立分析开场白。
- 前题提示显示题名，跨分类、来源、筛选与轮次跳转，返回恢复原范围。
- 筛选简化为全部／待答／已答，左上待答数量随选择、文字或题目反馈实时减少。
- 连续输入合并自动记录，失败保留输入并重试；复制固定到真实公开版本，不重复追加回答。
- 保留项目锁恢复、性能优化与 Q/D 短号交接；Windows 版本目录短暂占用时有限重试。

## 使用

完整解压 Designform-0.9.4.1-Windows-x64.zip，运行“策问 Designform.exe”。已有项目直接打开原目录，回答与历史继续保留。网页与 Windows 使用同一 main 源码及 v0.9.4.1 标签。

附件包含 ZIP、SHA256SUMS.txt 与 SOURCE.json，记录校验值和源码提交。项目格式继续支持 1 / 2，接口协议为 1。

## 验证

类型检查、两端构建与运行时打包通过；隔离虚构项目人工核对前题跳转、返回恢复、自动记录、条件解锁、分轮汇总与即时待答计数。默认未运行自动化测试套件。详见 [检查记录](https://github.com/Syurli/Designform/blob/v0.9.4.1/docs/protocol/QA_0.9.4.1.md)。
