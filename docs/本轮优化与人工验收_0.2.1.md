本轮按用户确认的五项需求实现，供人工验收。原有 3D / 分层切换 1150 ms、进入和返回关系分析 520 ms、分析内切换 360 ms 保持不变。

## 已修改

1. 浅色主题改用雾灰蓝：画布 `#c7cfd5`、面板 `#d0d6da`、阅读与卡片 `#dde1e1`、输入面 `#e1e4e2`。桌面标题栏与菜单配套降亮度；文字与链接保持清楚。
2. 品牌区为“策字图标 + 问”，系统完整名称仍是策问。项目入口恢复文档图标；功能按钮与知识节点继续使用自身语义图标。软件图标、任务栏、托盘、网页标签继续使用品牌图形。
3. 3D 总览以有效 GDD 为中心，近核规则、系统星团、DD 与细节形成层次；背景旋臂不代表知识边。多份 GDD 时优先 `GDD.md`，其次按路径稳定选择；没有 GDD 时不虚构总纲。分层与关系分析保留现有操作。
4. 正文内链接可悬停或键盘聚焦预览，点击跳到文档或锚点，支持返回上一阅读位置。同名且目标唯一的其他 GDD/DD 提供自动阅读链接。功能性关系表后置并折叠，路径信息在文末；普通规则表格正常显示。摘要取 `summary` 或正文首段，历史查看使用当时内容。
5. 随附 `cewen-collaborate` Skill 增加 `references/WRITING.md`；新项目格式说明、虚构模板同步采用自然文字链接与文末功能索引。没有重写任何已有用户项目或历史快照。

## 文档规则

自然引用使用标准 Markdown 相对链接。正文显式链接生成引用边，重复链接去重，已有同向语义关系不重复生成引用。同名词自动提示只服务阅读，不擅自改变正式关系。代码、标题、已存在链接不自动嵌套链接；同名多目标不猜测。

必要关系索引增加“来源身份”列，以便放在文末仍能准确归属到原规则。旧规则下关系表继续可读。关系管理面板对正文派生引用提示直接修改原文链接。

## 建议人工验收顺序

- 新建“纸上远行”示例，切换深浅色，观察大面积背景、菜单、输入框和桌面外框。旧示例正文不会自动迁移。
- 检查左上角“策 + 问”、项目图标、任务栏和托盘图标。
- 在星图查看中心总纲，旋转观察旋臂和层次，切到分层，再进入及返回关系分析。
- 打开“地图结构”正文：首次与重复出现的“时间节奏”都有链接；悬停看摘要，点击阅读全文并返回上一处。
- 点击“休息成本”等规则链接，确认定位到对应章节；在文末展开关联依据，普通正文不被关联表打断。
- 在编辑器“预览正文”查看相同阅读效果；点击文档链接会先保留草稿，再进入阅读页。
- 切换历史版本核对当时正文与摘要，再回到当前版本。给另一 LLM 使用随附 Skill，检查其实际写作是否符合规范。

## 验证边界

执行类型检查、生产构建、运行时构建及浏览器界面检查；未执行自动化测试套件。配色舒适度、星系观感、Windows 原生外框与托盘效果由用户本轮人工验收。真实游戏接入仍留在独立的游戏策划工作流。

实际检查：浏览器创建本轮独立示例、切换深浅色和星图 / 分层、点击“休息成本”并聚焦对应章节、返回上一阅读位置；重复“时间节奏”在正文中呈现两处链接，关联依据折叠在文末，浏览器错误日志为空。新版模板读取为 35 个节点、84 条关系、无解析诊断，并核对文末关系仍属于原规则。Skill 的 YAML 使用项目现有 YAML 解析器检查通过；独立 Python 校验器因环境缺少 PyYAML 未运行成功，不视作通过。
