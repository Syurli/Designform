# 策问 0.9.2 实施状态

保留原主面板与星空／分类分层／思维导图／卡片关系预览；文档画布嵌入原策划案区域，分类颜色同源。桌面菜单合并为一条窗口顶栏。

依据：[V2.1 产品与桌面交互方案](../策问_下一版本产品与桌面交互方案_v2_20260927.md)。版本号 0.9.2，发布通道为 prerelease，等待用户手动验收。

## 已接入主流程

- 启动进入项目库：固定分页、全库搜索和排序、创建／最后编辑时间、收藏、移除入口与二次确认删除。Windows 删除进入回收站；网页版永久删除前明确说明，拒绝删除授权根目录。
- 一体化创建：设想 → 可选项目预设（默认不选）→ 可编辑开场白和起步文档／分类 → 名称与目录。创建前不写项目，不调用模型。
- 原主面板内的文档工作区：保留知识空间／策划案／卡片库导航，加入文档树、临时／固定标签、自由画布、属性与模块编辑栏。分类、子文档、用途、标签和私人集合分开；用户 guide、问策及生产文档可见，媒体描述及索引隐藏。
- 文档预设：角色卡、地图卡、道具卡等生成普通文档；支持个人预设的空白创建、官方副本编辑、从文档提取、复制、置顶、删除。实例的文档／块／模块／行身份重新分配，外部引用改为占位。
- 文内组合：文字、图片、媒体、自定义字段、地图、对白、场次、分镜、问策等继续复用通用模块；拖入目录文档插入同源引用预览。问策、播放和生产从文档上下文进入。
- 保存：逐文档草稿与撤销、保存当前／全部／项目另存为、必须连带保存的新引用提示、结构草稿独立、保存冲突保留两侧内容。另存为保留集合和候选提案，候选不自动应用。
- 临时学习：纸上远行、角色道具、地图、游戏、世界观、雨夜候车室、最后一盏灯和进阶综合示例。示例在内存运行，关闭不保留；Ctrl+S 先另存为，取消不创建本地项目。
- 桌面命令：统一顶层菜单，左键平移、二维右键框选、三维右键旋转；F2 原位命名、Shift+F10、菜单键、保存及查找快捷键。窄窗口可打开属性编辑区域。

## 验证边界

实际结果见 [0.9.2 QA](../protocol/QA_0.9.2.md)。功能接入不等于全部设备与长期创作验收。原生中文输入法候选窗、系统目录选择器、文件权限异常、不同 DPI、多窗口并发及长时间大媒体库仍需用户验收。

ComfyUI 结果为协议仿真，万类为契约检查；没有真实模型、付费生成或第三方应用验收。专业剪辑、MP4 输出、三维导演台、自动唤醒任意模型宿主仍不在已完成能力中。
