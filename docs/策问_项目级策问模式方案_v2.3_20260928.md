# 项目级策问模式方案 V2.3

状态：用户已批准并完成本地实现；2026-09-29 完成隔离人工界面复核，安装验收见本地来源清单。方案日期：2026-09-28。

本文依据本轮用户要求与当前源码整理，附件用于说明编辑光标偏移。附件中的文档正文只是示例资料，不作为工程指令。当前实现以所选文档组织问答，并在进入问答时替换原目录；本方案把策问提升为当前项目的独立工作模式。

## 一、入口和模式范围

- 项目打开后，点击左上「策问」即可进入；文档页的「策问」也进入同一模式，不再要求先选择分类或文档。
- 首次进入使用「全部分类、全部问题」范围；保存原阅读模式的分类、搜索、收藏筛选及标签状态。后续进入恢复上次策问位置，并始终提供清晰的全部问题入口。
- 策问按钮在模式中高亮，显示项目待答数量。再次点击保持当前作答，不清空或重启轮次。
- 没有项目时使用项目选择入口；没有问题时展示空状态，提供可预览编辑的提问开场白及问题导入入口。
- 初次进入显示第一道可回答的待答题；已有作答记录时恢复上次未完成题。仅有已答问题时允许回看原始回答。

## 二、保留分类、文档双栏

分类栏沿用项目现有层级、颜色、展开方式和固定／标准／抽屉偏好。只保留含问题或含有问题文档的分类及其祖先；点击父类汇总后代。左上保留全部分类入口，底部路径继续只读显示。

文档栏包含两类条目：有相关问题的普通文档，以及可直接作答的问题。默认按「文档 → 轮次 → 问题」组织；点击文档直接进入其待答题并展开问题，点击具体题目直接打开该题。文档行显示待答数量，题目行显示作答状态。多轮内容可折叠，列表保留搜索与滚动，不要求额外弹窗选择。

「全部问题」提供平铺列表，保证用户可以直接跨文档定位。未关联普通文档的问题保留在「未关联问题」；来源失效的问题仍显示并标记待复核。全部问题默认同时包含未答、草稿及已答；归档问题由原有显示归档开关控制。

问题与文档以已有明确关联为依据：文档目标、段落来源和模块所属文档共用稳定问题身份。同一题关联多篇文档时，各文档下均可定位，但全项目数量、回答草稿与提交按问题身份去重。浏览分类不改写问题的正式归属。

## 四、分页与作答

- 分类、文档、轮次和题目都可以直接切换；切换前暂存当前输入、选项和作答方式。中文输入尚在组合时不抢走焦点或替换表单。
- 「下一题」沿当前文档／轮次前进；从全部问题列表作答时，沿当前筛选结果前进，并显示所属文档和轮次变化。
- 「暂缓」「前提不成立」继续作为明确作答方式。条件尚未满足的题目可查看，显示前题及原因；满足条件后更新可答状态。
- 已答问题保留原始回答，可追加改答；题目、来源或前题改变时保留旧草稿并标记待复核。
- 当前筛选为空时只展示该范围空状态，不改变项目的题目或回答。

## 五、汇总、提交与模型分析

切题、切文档及切分类只暂存。本轮汇总按所属文档组织题目和原话，用户核对并勾选后提交，允许只提交已填写的部分。其他轮次草稿独立保留，可从全部草稿查看并分轮提交；本轮汇总不把其他轮次的回答自动混入。

提交成功后提供绑定本次实际提交的可预览编辑开场白：让 LLM 读取已保存问题与原始回答，先分析整理，再询问是否开始下一轮并等待用户答复。草稿与未勾选的回答不作为已提交内容交给模型。

新增问题只更新数量并提示，不跳离正在作答的题目。用户完成提交后，问题仍可从已答范围回看；新轮次有明确提示，用户主动进入。

## 六、返回阅读

「返回策划案」或主动切换文档／自由视图退出策问模式，恢复原分类、文档标签、滚动位置及画布镜头。回答草稿继续保存。退出与再次进入均不提交回答、不修改正文、不开启下一轮。

## 七、输入光标调整

附件显示光标低于文字行、颜色偏淡。当前编辑器启用额外绘制的虚拟光标，需要核对其坐标与实际字符矩形、编辑区域及画布缩放的关系；尚未进行界面复现，不能仅凭截图判定唯一原因。

拟调整为：光标与当前字符位置、字体高度对齐；使用适合深浅主题的强调色、约2px宽度和正常闪烁。文档／自由两种视图共同核对普通段落、标题、换行、混合字体、中文输入法和平移缩放，避免用固定像素上移掩盖不同字号的问题。文字本身的字体、字号、行距和排版保持。

## 八、后续实施边界和验收

实施时复用现有问题身份、答案草稿、条件判断、原始回答追加及模型交接规则，新增项目级选择状态和目录显示范围；不更改历史快照或原始回答。本方案阶段仅新增此文档，未修改程序、构建、安装或发布。

验收重点：无需先选分类即可进入；全项目问题及有问题文档可直接点击；跨文档题目按身份去重；切换不丢草稿；条件题和来源失效题可见；汇总提交范围明确；新题不抢焦点；返回阅读状态恢复；两种视图输入光标与文字对齐。
