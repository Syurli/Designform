# 0.4 创作体验验收记录

2026-09-22。功能分支 `codex/0.4-authoring-experience`，供人工验收。只使用独立虚构项目；未接入或改写真实游戏。

## 本轮交付

- 桌面、桌面打开的本地网页与开发服务使用原生文件夹窗口；静态网页沿用浏览器目录授权。目录只读展示，取消保留原路径，复用上次有效选择。
- 项目中心可组合游戏类型、阶段目标、玩法、平台、团队资源、体验时长与自定义约束；实时生成可改写开场白，也可用同一设想创建项目。勾选内容保存为待细化的创作起点。
- 八类协作场景：构思、导入、接入、写作、问询、一致性审阅、根据回答迭代、版本交接。带真实修订与接入位置；复制不代表连接，不自动采纳设计。
- 正文工作台直接编辑标题与正文；短文件头、路径和关系管理按需展开。保留原始 Markdown，提供阅读预览与高级源码；本轮不是完整所见即所得编辑器。
- 未完成新稿可恢复，第一次保存才创建正式文件。临时图片随草稿保留，与正文同批保存；单张 3 MB、附件合计约 6 MB。
- 14 类常见 DD 分类，按类型推荐目录，可自定义、改名、改色、调整顺序和删除后迁移成员。公开登记位于 PROJECT.md；历史快照保持原样。
- 星图空白、分类与文档右键各有对应操作；右键拖动继续控制镜头。无总纲时可先写 DD。
- 每个有效 DD 提供星尘，整体上限 9000；轻微流动、呼吸与生长支持暂停和减少动态效果。浅色分类颜色在节点、目录、卡片、图例统一加深。总纲保持普通标签、金色字体，收紧光晕。
- 保留既有总览切换 1150 ms、关系分析进入 520 ms、内部聚焦 360 ms。
- 根据现场反馈，桌面标题栏移除重复图标与品牌文字，仅保留“应用 / 编辑 / 视图”、拖动区和系统按钮。主界面品牌保留一处；网页版不受影响。
- MCP 连接面板改为直接“复制 MCP 接入开场白”，原面板内可展开预览修改；不跳通用模板窗口。专用提示只处理工具连通、项目身份和模型名称，策划任务另行发起。网页端明确使用文件协作开场白。

## 人工验收重点与覆盖边界

依次体验：设想组装 → 选择文件夹 → 直接写 DD → 关闭恢复 → 保存 → 右键分类 → 浅色与深色切换 → 复制协作开场白。

请特别判断星尘密度、总纲呼吸和写作空间是否合适。尚未完成大规模 DD 的性能压测；图片附件与外部同时修改的复杂组合没有完整逐项人工覆盖。静态网页的目录重新授权本轮未重复验证。不同模型宿主的自动配置取决于各宿主能力，不承诺粘贴即可全部自动连通。

新版分类项目使用 0.4 或更新版本打开。正式 Pages、稳定安装目录与 GitHub 正式发布保留原版，验收候选单独交付。战术巫师接入仍由用户在游戏策划任务按独立流程发起。
