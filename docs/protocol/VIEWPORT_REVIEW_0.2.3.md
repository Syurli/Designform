# 策问 0.2.3 · 星图为详情留出视野

右侧详情采用浮层，之前星图仍按整个主体区域居中，打开文档时容易挡住中心附近内容。本次将星图与底部工具条平滑移到剩余区域的中心。

## 行为

- 星图、系统分层：详情展开后左移面板宽度的一半，收起后回位。桌面详情宽 290 像素，对应左移 145 像素。
- 画布尺寸、相机旋转、缩放不因详情开关而变化；节点、标签、连线与选中光环一同移动，点击坐标随真实画布位置计算。
- 过渡为 280 毫秒，快速开关从当前屏幕位置续接，不累积偏移；系统要求减少动态效果时直接完成。
- 关系分析继续使用已有的可读卡片区域；进入与返回通过已有屏幕坐标转换衔接。3D 与分层原有变换时长不变。
- 窄窗口按实际详情宽度计算偏移；本次不改写任何项目文档或公开版本。

## 人工检查

1. 选择总纲或 DD，确认星图中心位于详情左侧的可视区域中间。
2. 旋转或缩放后关闭详情，确认只有画面回位，原角度和缩放保留。
3. 再次打开并点击空白，确认取消选择仍可用，没有累积偏移。
4. 选中时切换系统分层、进入关系分析再返回，确认节点、连线和文字没有错位。
5. 改变窗口宽度、切换主题，检查底部工具条与星图保持同一中心。

开发检查使用类型检查、生产构建与人工浏览器操作，没有执行自动化测试套件。桌面主观效果由用户验收。
