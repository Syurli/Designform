# 文档栏与收藏规则（0.9.2 本地追加版）

## 分类与显示

- 点击分类名称选择筛选，并在同一分类栏内展开或收起其子分类；没有分类分页或进入下一页操作。
- 上级分类汇总自身及任意下级分类的有效文档，子文档一并显示；“全部文档”解除分类筛选，显示全部有效文档，包括总纲。
- 分类栏默认保留颜色及中文首字／英文首字母，悬停后以正常布局挤压文档区展开，不覆盖名称。左上按钮切换固定、标准、抽屉；最左侧及键盘焦点均可触发展开。右键菜单开启时保持展开。
- 任意深层树以迭代方式渲染，横向缩进最多三级，悬停深层时压缩祖先行。右末端的明确箭头展开／收起子分类，悬停分类轻微抽出。
- 底部路径只展示当前筛选数据，不再作导航或拖放目标。顶栏使用当前分类色块与名称并柔和过渡，不保留旧重复标题或层级页码。

## 排序与图钉

- 名称默认按中文拼音／英文首字母和数字自然升序；创建、最后修改时间按新到旧；用户顺序由列表拖动或右键上移／下移调整。
- 公开 `PROJECT.md` 的 `documentListOrder: [文档身份, ...]` 表示跨层级的展示顺序，不改变 `system`、`parent` 或正文。已有 `documentOrder` 仍作为未整理文档的初始手工顺序。
- 文档区内拖动只调前后顺序，拖到正式分类才移动归属；升降级保留在明确的右键命令中。工作区内的公开顺序更改先暂存，保存全部后写入项目。
- 时间来自已验证版本：创建时间是文件首次被版本记录的时间，修改时间是最近内容变化版本的时间；历史视图只使用截至该版本的记录。导入前未知的时间不凭空补造，旧文件同次初始入库可有相同时间。
- 目录、文档卡片视图和主卡片库共享所选排序；主卡片库只生成文档卡片，正文或小节搜索命中折回所属文档，不另铺分类和小节卡片。滚轮／触控板按连续手势翻页，窗口变化重新计算分页容量。
- 每个正式分类、全部文档、收藏分类和最近列表分别保存图钉，当前范围内图钉优先于任何排序。总置顶是独立快捷入口，不改变分类和原列表成员；示例默认只把总纲加入总置顶，用户可移除或追加任何文档。
- 文档行不显示三点按钮；右键、菜单键、Shift+F10 第一层统一为“卡片关系预览、改名、条目颜色、更多”四项，其余文档操作进入“更多”。右側常驻星标收藏，图钉切换当前范围内置顶；总置顶图钉移除快捷入口。图钉、排序与其他控件共用 Lucide 1.65 细线样式。
- 把手默认隐藏，按住条目约 250ms 显示并启用拖动；松开或取消手势后恢复。双击文档直接打开策划案，不触发改名。
- 总置顶标题空闲缩为装饰虚线，靠近或键盘聚焦才显示文字；没有总置顶项时进一步缩高。
- 已置顶的文档块始终可见，不随标题提示文字隐藏；项目身份、文档工具与搜索区压紧纵向间距，为文档列表释放高度。

## 收藏与个人数据

- 切换收藏、最近时清除正式分类及搜索筛选，进入各自完整范围。搜索只在当前分栏中匹配，不绕过收藏或最近范围。
- 文档“更多”中的收藏分类入口可勾选多个个人分类，例如“今日任务”“昨日待讨论”；也可多选文档批量设置，混合成员选项保留未改动文档的原关系。新建收藏分类可把当前多选文档作为初始成员。也可把总置顶区文档拖到收藏分类中，增加该分组成员。
- 收藏分类支持新增、名称／颜色修改及删除；删除分类保留收藏和正式文档。取消收藏会移除该文档在所有收藏分类中的成员记录。
- 排序选择、图钉、收藏及最近保存在当前项目的本地个人偏好中；树展开和筛选单独保存。已有目录收藏／最近偏好读取后沿用；临时示例仅保存在内存，不写持久整理或公开正文。
- 旧 `.cewen/workspace.json` 中的工作集合只读投影为收藏分类，原集合 source 保留，不删除或改写源记录。集合内的小节引用折回所属文档，分类身份不误映成总纲；暂时无法显示的原引用仍保存。读取失败保留现有收藏，并允许之后重试；历史阅读不执行导入。
- 个人偏好保留迁入集合的来源身份 `sourceCollectionId`、父级、说明、顺序、可见范围、标签、状态和创建／更新时间。一篇文档的多集合成员关系继续保留；记录已导入的集合身份，用户删除收藏分类或取消收藏后不因再次打开项目而恢复原成员。个人收藏修改不回写旧集合或正式分类。
- 这些操作不会自动连接模型、创建问题、修改用户历史快照或复制正式文档。

## 目录拖入正文

- 文档视图接收目录文档拖放时写入标题链接，采用目标文档所属分类色；文字段落中的落点优先原位插入，不展开来源正文。
- 自由视图继续在画布落点生成独立文档引用对象，可以单独摆放；源身份、源正文与正式分类不变。
- 目标文档锁定、历史只读或拖入自身时不写引用。收藏、最近和目录导航保持个人阅读行为，不把导航自动转成正文修改。
