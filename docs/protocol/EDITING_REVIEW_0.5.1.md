# 0.5.1 创作入口与章节分类验收记录

2026-09-23。使用虚构项目验证；不包含真实游戏资料。文档格式与接口协议仍为 1。

## 本轮实现

- 项目库专用于最近项目、打开、复制和移除记录；新建项目进入独立设想页，可直接创建空白项目。游戏类型、本轮目标、玩法、平台可多选和自定义；开发资源、单次时长保持单选。私人草稿保留选项及手改开场白。
- 协作开场白读取真实 MCP 客户端心跳。在线时优先核对已有工具，未连接时提供接入步骤；其他客户端在线不代表当前对话已接入。网页版采用文件协作提示。连接状态变化不覆盖手改正文。
- 文档头部 `aliases` 保存缩写与别名；输入标题或别名会出现候选，选择后写入真实的相对 Markdown 链接。不会仅凭同名就建立正式关系。
- 系统分层的总纲位于顶层。带锚点章节通过公开的 `sectionSystems` 映射独立归类，原文仍位于所属 GDD / DD；分层显示分类实线，关系分析可追溯文档归属。缺少映射表示继承，`system-unassigned` 明确表示未归组。删除分类时同步迁移文档与章节映射。
- 二维空白拖动框选，右键平移；三维 Shift + 空白拖动框选，普通拖动旋转。Shift 可追加选择，多选节点可一起摆放；二维中的可分类内容可批量拖入分类，结构变更仍需保存版本。
- 写作区改为顶部保存与导航、紧凑工具栏、正文纸面；属性和关系按需展开。修复 Crepe 浮层样式作用域，避免底部出现裸露的块菜单。图片拖动下方手柄调整尺寸，公开文件用标准 HTML 图片宽度保留。

## 已完成的检查

- `npm run build:all` 通过：TypeScript、桌面前端、静态网页和运行宿主构建成功。Vite 仍提示主资源较大，未阻止构建。按工程约定未运行自动化测试套件。
- 本地服务浏览器人工检查：项目库与创建页分离；平台 PC 与移动端可同时选择；无 MCP 心跳时生成接入提示；深浅写作布局均无裸露块菜单。
- 基础示例中，将“轻量探索体验”拖到“体验方向”，出现新的分类实线并保存结构版本；二维空白拖动实际选中多个节点。
- 虚构 DD 输入标题后选择候选并保存链接；登记“图例 / IMG”别名后，输入“这里使用图例”只补全末尾别名，前面的正文保持不变。
- 虚构 PNG 图片拖至 260px 后保存为 `<img ... width="260">`，阅读预览宽度正确；关闭重开及 Markdown / 正文往返均保留尺寸和替代文本，无修改保存提示不创建重复版本。
- 静态网页生产包在 `/Designform/` 基路径启动，项目库和创建页正常；显示文件协作提示。多选平台、手改开场白返回项目库后再进入均保留。

## 仍需用户验收的组合
