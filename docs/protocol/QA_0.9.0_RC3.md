# 0.9.0-rc.3 示例与本地版本验收记录

本轮从已合并的 `main@809e462` 接续。旧版 rc.2 检查记录见 [RC2 验证](QA_0.9.0_RC2.md)，不得当作本轮新提交的通过结果。

## 本轮变化

- 项目库统一“浏览示例”入口，预览只读取内置文本；只有明确点击创建练习副本才写入项目和媒体。
- 网页版基础示例模板改为按需写入；普通启动不反复覆盖浏览器本机模板文件。
- 预设新建与追加仅提供空白起步结构，正式项目明确选择目录。
- 新示例的文档写入带父子关系的分类；追加前保留已有项目分类。地图源与使用覆盖层继续使用独立对象身份。
- 桌面“关于策问”显示版本、作者、仓库。
