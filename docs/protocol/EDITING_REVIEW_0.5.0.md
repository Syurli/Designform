## 建议人工验收顺序

1. 在虚构项目新建 DD，直接进入富文本正文；输入中文、插入标题和表格，按标题插入另一 DD 链接。保存后重开，检查 Markdown 中的链接、表格、文字及反向引用。
2. 在 2D 拖 DD 到分类或“未归组”，检查 `system` 与结构实线；再新增手工关联，确认原正文引用仍在。接着分别断开、改接现有线端，检查目标、来源和保存后重建结果。新增关系与改接旧线应显示清楚的预览。
3. 试画布同项目复制、粘贴与剪切、粘贴：复制应产生新 DD；剪切后的粘贴应改变分类。分别验证菜单和 Ctrl+Z / Ctrl+Y、Ctrl+S，确认一次语义拖动可整次撤销，保存版本包含正文与关系的同一批变动。
4. 开启快速晃动后，仅用普通手工 `relates` 线验证预览、断开与撤销；默认开关应为关闭。分类实线、正文引用及强语义关系不应被晃动删除。删除或改接正文引用时，应只改选中的具体一处并保留原文字。
5. 在 3D 拖动节点并撤销，重开检查坐标保留，确认 Markdown 的分类及关系不变。切换 2D、3D、关系分析，检查结构实线与关联虚线在深浅主题下可辨。
6. 用静态网页授权一个虚构项目文件夹，重复新建、富文本编辑、保存与重开；再核对权限撤回和外部修改冲突的恢复提示。
7. 小型 PNG 粘贴已检查；复杂剪贴板图片、中文输入法组合输入、较大图谱性能与完整块拖动组合仍留待人工验收。原生 Windows 包体检查另见发行记录。

## 边界与发行准备

Markdown 与正式版本是权威数据；`.cewen/` 保存私有草稿和 2D / 3D 坐标。3D 摆放不改变语义，也不单独制造策划版本。画布复制、粘贴限同一项目。正文引用修改须定位具体一处，保留原文字；保存正文、分类、关联和附件时按同一事务处理。

网页多标签同时访问且强制刷新时，曾出现短期项目锁提示；等锁过期后从最近项目重开恢复，文档和图片完整。现行网页文件锁租期为 30 秒，此次未调整既有锁协议。浏览器文件夹权限撤回、全部高级手势组合及大项目性能不属于已完成验证。
