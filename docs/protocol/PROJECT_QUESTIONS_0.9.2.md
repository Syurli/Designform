# 0.9.2 本地项目策问模式

初版日期：2026-09-28；作答与交接流程于 2026-10-07 修订，当前行为以 [0.9.3 策问流程规范](INQUIRY_FLOW_0.9.3.md) 为准。

## 入口与阅读恢复

左上品牌按钮、正文工具栏的策问按钮均进入当前项目的统一策问模式，无需先选分类或文档。首次查看全部分类和问题，后续恢复独立的策问范围、状态筛选、搜索与题目位置；全部问题提供扁平定位，未关联问题保留独立入口。没有项目进入项目库，没有题目提供项目提问开场白的预览编辑入口。

阅读目录的分类、收藏、最近、搜索与展开状态不参与策问筛选。正文标签、滚动位置与画布实例继续保留；属性侧栏只在策问模式中临时隐藏，返回后恢复原开关。跨主视图进入策问，返回恢复进入前的主视图。再次点击策问只显示当前会话，不重置作答。

## 来源、状态与范围

问题以稳定 ID 为身份。文档目标、规则节点、创作对象及引用、段落锚点均映射到真实来源；缺失身份不猜测删除。目录呈现含问题的分类及祖先、普通文档、轮次和问题。索引、README、问题文件与媒体文件不生成普通来源文档卡片。同一题可出现在多个来源文档下，但数量、草稿和提交只计一次。

全部、待答、已答是个人导航筛选；草稿显示已答 · 待保存，变化后的旧回答显示需复核并回到待答，归档开关控制是否查看归档题。条件未满足仍显示题目与原因；前题提示可点击跳转，返回恢复原范围，禁止越过条件输入及保存，但不清除原草稿。题目、来源或前题改变时旧草稿保留，复核信息默认折叠；修改当前表单即可更新个人基准，不能改写历史答案。空锚点不触发来源不存在或复核提示。新增题只更新目录及提示，保留当前输入焦点。题目已移除的草稿保留在其他轮回答入口中。

分类展开、固定／标准／抽屉外观与母层级压缩使用独立偏好，不改原分类结构。问题筛选按父分类聚合后代，文档栏只展示对应问题的普通来源。

## 本机回答、保存与协作

切题、切分类、切文档、退出、Ctrl+S 只暂存个人回答草稿。私人草稿继续使用既有按问题 ID 的存储，项目策问会话使用 `__project__` 独立键；不会迁入正文阅读的分类筛选。临时示例只在内存保存。

轮次身份继续使用 `questId` 与 `roundId`（缺省取轮次名称），不按显示名称误合并不同 Quest。前后题跟随当前范围，可以跨文档和轮次；切换时说明来源或轮次变化。本轮汇总覆盖全项目同轮问题，按来源归组、多来源只列一次。汇总自动收集当前轮已填写回答与问题反馈，不再要求二次勾选。空白题暂缓，其他轮本机回答保留；复制或预览开场白时保存当前轮回答，不隐式跨轮保存。

提交继续使用既有 answers 服务、基础哈希与幂等请求 ID，原始回答以追加记录保存。收据绑定本轮最新已保存回答及有效来源身份，并给出保存版本与题数；无源题以问题身份交接。复制或预览分析开场白不自动连接模型，也不授权续轮。LLM 读取公开已保存原话、分析、提出待确认修改；须等待用户明确同意才发布下一轮。

## 正文光标

关闭 Crepe 未处理画布缩放的虚拟光标，保留拖放与块间定位。替代光标使用浏览器实际折叠文字 Range 的视口坐标，在顶层绘制固定 2px 宽度，不占正文布局；跟随滚动与画布缩放并尊重裁剪。文字末尾贴住自适应块边缘时，光标整体收进可见区域，避免裁成接近 0px 的细线。选中文字、失焦、只读和输入法组合阶段回到原生光标，不干扰选区与候选窗口。不支持顶层浮层的环境保留原生光标。字体、字号、行高与阅读排版不随此修改。

## 验收边界

使用隔离虚构项目进行人工界面与真实服务提交复核，必要类型检查、桌面／网页／运行时构建；默认不运行自动化测试套件。验收结果在 `QA_0.9.2.md` 和本地安装的 `LOCAL_BUILD.json` 单独记录，未覆盖真实输入法与不同系统 DPI 时如实说明。
