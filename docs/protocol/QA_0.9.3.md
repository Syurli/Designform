# 0.9.3 发布检查

本次发行包含 0.9.2 之后的目录、项目策问、原位编辑、创作组合、连接会话、实时工作稿、Pages 本机接入、输入与浏览优化。应用版本、锁文件、正式发布意图及 README 同步为 0.9.3。

## 已完成的本机检查

- 本轮源码的类型检查、桌面/网页生产构建、桌面运行时和 Windows 发行构建。
- 隔离虚构项目人工检查：归档切换、引用跳转与返回、两种视图列表对齐/续号/项内换行/退出、连续换行、引用末尾普通续写、段落转换、分类子菜单、改键保存、关于页。
- 已安装包文本资源与启动器核对；安装自带运行时和 CLI 在隔离空工作区正常启动。
- 正文工具区排除旧属性面板 section 间距，段落、文字、格式刷在同一侧栏紧凑排列。

按工程约定没有运行自动化测试套件。历史人工检查见 [QA_0.9.2.md](QA_0.9.2.md)；输入行为见 [INPUT_INTERACTION_0.9.2.md](INPUT_INTERACTION_0.9.2.md)。

## 未覆盖项

实体鼠标侧键、原生右键拖动、Windows 输入法完整往返、真实第三方模型/ComfyUI 工作流与长期大型资料库未在本轮实机验收。侧键、手势仲裁和默认浏览器转交已按源码路径核对；构建成功不代表硬件检查通过。

## 发布来源与本地清理

GitHub main、v0.9.3、Pages 部署和 Windows Release 必须对应同一源码提交。Windows 附件 SOURCE.json 记录标签、提交及包摘要，SHA256SUMS.txt 提供包校验。最终成功状态以 GitHub Actions 与 Release 实际回执为准。

本地保留源码、文档、私有设计笔记和当前 0.9.3 安装/发行包。旧构建输出、重复发行包、开发验收缓存及临时日志在成功发布后清理；被进程使用的安装目录保留至退出。真实项目及迁移前备份不在清理范围。清理明细随本机发行收据保留，不上传私人资料。
