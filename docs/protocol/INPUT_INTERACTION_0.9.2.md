# 输入、右键与浏览体验优化（0.9.2 本地构建）

## 正文与工具区

- 引用单击优先跳转，Alt+单击进入引用文字编辑。链接右边界不继承 link mark；空白输入切回普通正文。行内链接允许折行。
- 文档与自由视图共用列表：Enter 继续编号、Shift+Enter 项内换行、空项 Enter 退出。连续 `<br>` 作为安全换行解析，源码不会作为文字显示。
- Milkdown 列表 NodeView 的序号和正文使用同一首行顶边；内容包装层内的首段不继承额外上下间距。
- 右侧工具常驻段落、文字、格式刷。段落样式直接转换当前段落，不插入占位文字；选区与撤销由当前编辑实例维护。
- 媒体许可或来源留空时记录“来源与许可待确认”。新项目、文档名称留空使用默认名称；项目目录与引用目标仍需有效。

## 插入与手势

- 插入按“正文与引用 / 图片与媒体 / 角色与地点 / 剧情与演出 / 设计与决策”分类。所有现有模块都有入口，新类型回落到设计分类。
- 菜单支持方向键、Enter、Escape。子菜单自动向可用方向展开并避开视口边缘。
- 右键菜单延后至松开，超过设定距离只触发拖动。兼容 Windows 按下阶段发送 contextmenu 的顺序；普通输入框保留系统上下文菜单。

## 导航与设置

- 浏览历史记录本项目的文档、视图、章节、卡片页、策问及项目库，最多 120 项。退回后打开新页面会截断前进历史。
- 浏览只恢复个人阅读位置，保留打开的草稿，不自动保存、提交版本或离开项目。切换项目会清空历史。
- 左右箭头按钮、Alt+Left/Right 与鼠标侧键复用同一历史控制器。Windows app-command 与 DOM 侧键事件去重。
- 文件/帮助菜单可打开“快捷键与鼠标设置”；默认 Ctrl+,。可改应用快捷键、交换/关闭侧键、调整右键拖动距离、关闭主题动画。
- Ctrl+C/V/X/A、Ctrl+Z/Y/Shift+Z、Delete 在文字控件沿用原生编辑；块选择在自由视图使用块剪贴板与可撤销删除。创作模块粘贴生成新身份，媒体仍共享原素材。
- 文档目录 Delete 进入删除范围确认及结构草稿。图谱文档删除复用此流程；规则节点先定位来源正文，避免把删除规则误解为删除整份文档。

## 主题与许可

- 主题采用 280ms 柔和过渡。支持 View Transition 时使用旧/新画面交叉淡化，其他环境用颜色过渡；系统减少动画偏好与“立即切换”均受尊重。
- 关于页显示作者李仕林、GitHub/网站链接、MIT 使用条件及许可全文。桌面新窗口链接由 Electron 转交系统默认浏览器。
- 自有源码许可在根目录 LICENSE 与发行版 LICENSE；网页公共资源包含 licenses/MIT.txt。第三方许可与用户项目版权不被自有源码许可覆盖。
