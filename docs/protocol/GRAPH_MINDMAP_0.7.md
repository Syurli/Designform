# 知识空间脑图与阅读方向（0.7）

`GraphMode` 增加 `mindmap`。同一 Three.js 场景和同一节点按钮在星系、图层、脑图与关系焦点间移动。入口调用 `graph.setMode('mindmap')`；点击脑图节点后应用先设选中，再调用 `graph.setMode('network')`；返回时调用 `graph.setMode('mindmap')`。关系分析仍由 `network` 承载，应用负责导航状态和返回按钮。

`graph.setDirection('vertical' | 'horizontal')` 控制图层、脑图及关系焦点方向，方向使用独立布局缓存键。应用侧需保存当前方向偏好。脑图用公开 `contains` 关系建立一棵展示树：目录章节优先于分类投影，同节点只选择一个父节点，检测并排除归属环。总纲在纵向顶部或横向左端；无父节点的条目保留为额外根。默认只让总纲、分类与文档参与排布，小节需详细模式、筛选或关联显式展开；筛选后的可见层级独立记忆坐标。每层独立居中排布，大型子树不会把首层分类推离屏幕；更深层通过平移阅读。跨文档关联仍在数据内，脑图总览仅绘制本树的包含边，进入关系焦点再显示完整的实虚线关系。

总纲及其未归类章节显示“游戏总纲”和金色；分类卡片及已归类章节使用分类色，其他未归组条目用中性色。筛选父分类会包含所有子孙分类，归属异常环会在查找时停止。

脑图摘要卡片沿用关系分析的原生按钮及四角展开变量。默认镜头采用约 85% 的一单位一像素投影，并为总纲卡片顶部留出阅读空间；纵向同层间隔 224px、层间 180px，横向同行间隔 144px、列间 260px。缩放时卡片与投影距离同倍率变化，避免固定像素卡片重叠。切换不销毁画布与节点，焦点切换约 360 毫秒、脑图或分析卡片进出约 520 毫秒，星系和图层总览沿用 1150 毫秒。退出焦点时优先恢复同方向的原镜头；窗口尺寸已变则沿用布局位置重新取景。三维星系拖拽只改变摆放；平面拖拽中的分类端口、关系端口和线段语义编辑继续按明确目标触发。一次拖拽及邻居回弹仍只写入一条编辑记录。横向图层的拖动边界在 x 轴，y 轴可自由移动。

转场为所有场景节点补全起点和终点。隐藏、筛选或退出中的节点优先锚定公开包含关系的父节点，再沿用旧位置；不完整旧项目中无分类的节点也获得确定坐标，避免动画帧因缺项反复报错。

人工验收：纵横脑图对照目录树与总纲位置；连续点击脑图卡片、返回、改变方向与调整窗口，检查卡片不中途闪烁；在关系焦点确认跨文档线及标签；在横向图层拖动文档检查 y 跟手与单次撤销。本轮实际检查与未覆盖范围见 [整体验收记录](WORKSPACE_REVIEW_0.7.0.md)，仍待用户验收。
