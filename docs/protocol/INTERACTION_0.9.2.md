# 本地交互与文档视图优化（0.9.2）

## 分类与图标

分类规则见 [文档栏](PROJECT_DIRECTORY_0.9.2.md)。固定／标准／抽屉为项目个人阅读偏好，任何模式展开都挤压文档区；抽屉只展开靠近的顶层分类分支。分类层数无限制，循环与缺失父身份仍拒绝。深层祖先行压缩、有限缩进及轻微抽出不改公开层级。

功能图标统一细线语言。图标所在按钮识别区域进入时播放一次轻动画：知识空间外圈小球绕转，卡片库四格张开，普通按钮轻移，图钉轻摆。离开和动画结束回到原姿态；减少动画偏好关闭这些动画。

项目目录下方只保留显示归档和展开规则。保存阅读视图移到顶边框的“视图”菜单，继续写入个人工作集合。

## 知识空间

星图拖动分类仅调整布局，不改变 `system`、`parent`、包含边或正文。完整公开包含子树通过广度优先传播，子分类、嵌套文档和小节以弹簧阻尼追随其父项当前位置；松手后完整跟随手势总位移。隐藏节点也保留其分支位移。固定节点及经它传递的支链不移动；减少动画时立即同步。

系统分层只让同层级的分类并列。竖向时分类同层横排，分类内文档与小节按公开前序依次向下；横向时分类同层竖排，分类内文档与小节依次向右。文档的嵌套只产生有限侧向缩进，不再并列成同一层。父分类内容避开已展示的后代分类深度。布局键为 `layers-v7`，不沿用旧文档并列坐标；旧明确固定节点仍保留。一次完整手势使用一条布局撤销记录。

## 文档视图与自由视图

两种视图使用同一 Markdown 草稿和撤销链，默认解锁并可编辑。普通正文单击后直接在视图内编辑，输入时只更新已有标签标题，不重建工具栏。文档视图在原段落内编辑；自由视图保留布局、章节落点与模块。右侧统一为上方工具、下方约三分之一的紧凑属性区，切换视图不把工具移入画布。焦点可以移入样式浮框；保存、切视图、切块或锁定时明确结束原位编辑，自由视图点击画布空白也结束编辑。正文刚挂载且编辑器仍在完成异步创建时，上述收尾也同步读取当前文字，不等待防抖通知。Ctrl/⌘ 单击正文链接继续导航。右上文档锁是项目和文档身份对应的本机个人偏好，锁定后保护正文、属性、插入、拖动、缩放块及撤销重做；仍可切换视图、复制阅读内容与平移缩放镜头。锁不是外部文件／MCP 权限管理；历史版本始终只读。

自由文本块以单个最小文字单元进入原位编辑，输入区贴合当前内容，不以整页大输入区占位；点击空白先退出文字编辑，再允许空白平移。文字块按内容自然估算尺寸，显式手动宽高继续作为用户布局。进入编辑同时读取并保留展示宽高的亚像素，编辑期间不重建节点或重新定位已操作的光标；退出编辑后按当前内容规则伸缩。编辑器与字体浮框从主题变量取色。网格覆盖整个视口，间距与原点随镜头缩放和平移同步。

原位编辑不继承完整编辑器的 360/400px 最小高度。换行生成的新块继承原块横向锚点，在前块后避让现有块；仅当前实例自动生成的落点可以让位。读入的既有布局、手动调整、锁定和内容组坐标保留，正文顺序和章节归属不因避让改写。隐藏画布通过离屏测量得到真实块高，不使用隐藏节点的零高度。

## 紧凑属性与标签

下方属性只保留名称、标签、状态及“文件位置”，使用较小输入框，不重复目录中的移动、归类和颜色操作。名称、标签或状态变化自动应用到当前文档草稿，不再要求点“应用”；中文输入组合完成后才应用。自动应用不等于磁盘保存，仍由保存当前文档／保存全部写入正式项目。文档锁继续保护这些属性。

原文档用途分类统一通过既有 `tags` 表达。新文档、官方预设和虚构示例将已有用途值合并到标签并去重，不再生成正文头部 `purpose`；已有资料读取时只作标签投影，不批量改写。用户实际修改当前文档属性后，才把该稿的旧用途值迁入标签并移除头部 `purpose`。正式 `type: gdd/dd/question/guide`、私有草稿用途以及地图覆盖层／生产对象的 `data.purpose` 保留，标签不改变文档协议身份。

“文件位置”在桌面按当前项目与文档身份打开对应的系统文件位置；网页提供路径信息，临时示例或未落盘的预设说明尚无正式磁盘位置。操作不保存草稿，也不创建项目。

## 落点插入、图片与文档引用

两种视图均可在原落点右键插入文字、章节标题、图片、文档引用或创作模块，无需切换右侧工具分页。自由视图将屏幕落点转换为画布坐标；文档视图按落点所在或邻近段落确定插入顺序。锁定及历史文档不接受插入。

图片单击或图片右键菜单可重新导入，也可在相邻落点插入另一张。重新导入保留当前块身份，仅替换当前草稿中的图片来源；新增附件在保存时写入，不覆盖其他文档引用的原图片。取消选择文件不改变正文。

目录文档拖入文档视图时，尝试在文字落点插入标题链接；无法插入原段落时，在该处顺序插入链接。标题采用目标文档所属分类色，不展开为带正文摘要的引用卡。拖入自由视图继续生成可独立移动的 `document-reference` 引用对象，指向源文档身份；两种操作均不复制源文档或改变其归属。

## 字体与文字配色

选中文字后的浮动工具栏提供加粗、斜体、删除线与“文字样式”。文字样式面板包含本机字体搜索与选择、荧光笔、字体颜色、字体背景颜色；独立清除各项或全部样式均保留粗体、斜体和链接等其他标记。控件操作保留原选区，不要求转到详情编辑。

Windows 桌面通过系统字体服务枚举当前用户和系统已安装字体家族，支持刷新，不扫描、复制或上传字体文件。网页在用户主动点击时请求浏览器的本机字体授权；不支持或拒绝时明确显示结果。字体未安装时交给浏览器回退，不删除正文中的字体选择。缺少斜体字面的中文字体允许浏览器合成斜体。

公开 Markdown 使用 `span data-cewen-text-style="1"` 及 `data-cewen-fontfamily/color/background/highlight` 保存有限样式。字体名和六位颜色经规范化；读取与展示重新生成安全 CSS，不执行原 span 中的任意 `style`。样式 span 包住 Markdown 粗斜体，避免句中中文出现普通星号；编辑器按文字与格式集合识别等价嵌套。荧光笔与整行字底色可并存，其他格式照常保存。该格式不改变文档身份、元数据或归属，也不包含本机字体文件。

## 文档栏滚动与项目载入

文档列表、总置顶列表及其行明确限制宽度并隐藏横向溢出，长标题省略显示，纵向滚动继续可用。分类展开和行悬停不能产生左右滚动条。总置顶文档始终展示，仅提示标题在离开时压为装饰线。

项目库、链接启动、示例及直接快照打开共用载入任务，分为读取项目文件、准备分类目录、准备文档内容、显示项目界面。读取服务没有逐文件进度时使用不确定进度；之后显示已完成阶段数，不使用计时百分比。每阶段绘制后执行对应工作，防重复打开，失败与取消清理面板。取消只阻止后续打开，不宣称中止已发出的磁盘读取；迟到结果不再打开项目。

## 卡片库

压缩标题区，禁用卡片列表纵向滚动。每页容量根据可用宽高计算，窗口变化调整容量并保持原页附近位置；前后页按钮、滚轮和触控板切换页面。连续触控板手势只翻一页，边界消化滚动以免穿透外层，Ctrl 缩放手势不作为翻页。排序继续与目录共用。单击选中保留稳定 DOM，双击打开对应策划案文档。

主卡片库只显示文档卡片。分类不生成卡片；正文／小节搜索命中折回所属文档，去重后仍只有一张文档卡片。卡片显示该文档的创建时间、最后编辑时间和最近实际内容变更版本标签；无记录显示“暂无记录”／“未入版本”。未保存文本显示“草稿”，不将项目的无关更新冒充文档修改时间。版本时间只来自已验证版本清单，不改写 Markdown。

文档目录与主卡片的文档右键统一为“卡片关系预览、改名、条目颜色、更多”四项；扩展操作收进“更多”，收藏分类设置支持多选文档，不把整套长菜单直接铺在第一层。

最新追加的卡片翻页、收藏迁移、紧凑属性和插入／引用行为已在本地源码实现，仍待人工验收；本文不将未完成的人工检查标为通过。本轮默认不运行自动化测试套件。工程检查、隔离虚构项目界面复核与本地安装结果分别记录于 [QA](QA_0.9.2.md)，不提交或发布线上版本。
