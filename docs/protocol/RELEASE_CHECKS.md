本包应用已更新为 0.2.4。以下保留首版检查事实；主题、总纲星系和阅读交互见 [0.2.1 人工验收](READING_REVIEW_0.2.1.md)，布局、空白取消及 LLM 连接见 [0.2.2 人工验收](WORKSPACE_REVIEW_0.2.2.md)，详情展开时的星图避让见 [0.2.3 人工验收](VIEWPORT_REVIEW_0.2.3.md)，最新总纲文字及品牌排版见 [0.2.4 人工验收](LABEL_REVIEW_0.2.4.md)。

## 交付范围

首版功能已实现：独立项目与 Markdown 编辑、公开完整版本、星图/分层/关系分析/正文/卡片、用户整理、导入导出与备份、问询与修改提案、CLI/MCP 及独立接入包。使用 Windows 便携目录运行，无需源码、npm 或单独 Node。

功能实现与验收覆盖分开记录。以下“已观察”只表示所列操作实际执行；不意味着跨机器、物理断电或第二个真实模型已经验收。开发没有执行自动化测试套件。

## 使用边界

本版采用线性完整快照，没有云同步、多人权限、历史分支/合并、内置模型推理或自动更新。导入/备份单包限制 150 MB、10000 文件。历史完整快照随迭代增长；撤销与后续修改重叠时返回冲突，要求人工比较。

外部多文件编辑应使用明确批次；普通文件监听只记录真正观察到的稳定状态。未知格式拒绝直接写入，后续格式升级须先备份并在副本迁移。损坏的锁记录要求关闭所有相关服务后保留并移出锁文件，不能随意自动接管可能仍在使用的项目。

用户后来发起的真实游戏接入 A1 与此开发任务隔离；接入中发现软件问题应保存脱敏复现并另发修正版。
