## 必须继续人工验收

- Windows 原生中文输入法组合输入、候选窗、剪贴板与系统目录选择器；浏览器脚本填写中文不能代替原生输入法验收。
- 原生窗口关闭和重载时带未保存内容的提示，125%／150% 显示缩放、触控板、长标题及长菜单。
- 真实工作习惯下的预设组合、分类移动、多个未保存标签、保存冲突比较和另存为目录权限异常。
- 网页版真实文件夹授权、权限撤销、跨窗口与桌面／网页交接。
- 真实 ComfyUI 模型／GPU／工作流与真实万类应用；现有检查分别是协议仿真及数据契约。
- 长期大型媒体、断电、磁盘满、回收站恢复。删除复核只允许虚构项目。

GitHub CI、Pages、Release 和本地安装来源单独以对应运行与产物的真实记录核对，不用本地构建结果替代。
