# 0.6 协作开场白任务与公开上下文

状态：开发中，待人工界面与实际模型接入验收。`shared/prompts.ts` 生成可预览、可手改的开场白；`src/prompt-panel.ts` 在通用创作及文档协作入口提供任务选择。目的明确的 MCP 接入、写作选区和版本交接入口直接保留原任务，不重新要求用户选择。

新增任务包括整理分类与别名、检查对白分支、汇总项目共享注释、比较设计色板、复盘内容变化。分类任务带入当前公开分类及本轮文档别名，区分主要归属、正文链接和手工关系。对白任务列出已保存设计块，要求核对显式跳转和稳定 ID，保留正文内选项预览与独立编辑同源。色板任务列出正式色板，区分设计意向和图片提取候选，不虚构源图面积。内容复盘只给出已保存范围的可读字符、图片引用、对白和色板摘要；实际版本增删须再读取历史，不能用净字符差替代。

注释任务只列出本轮文档实际存在的 `docs/annotations/<文档ID>.md`、`.ink.json` 和相关公开布局 `docs/layouts/<文档ID>.json`。开场白不自动载入 `.cewen/` 的私人注释、草稿或个人镜头。所列路径只是公开材料线索；若当前对话没有本地工具，模型须请用户主动提供文件或上下文包，不能把项目路径当作已获文件访问。`cewen_context` 可在真实 MCP 连接可用时读取所选文档的公开伴随文件。

通用协作与新任务共用原有连接状态逻辑：先核对当前对话是否有策问工具，客户端心跳不能证明本对话已接入；网页版只按用户提供的文件协作。手改开场白不会因心跳变化被覆盖，复制也不代表发送、采纳或创建版本。测试时应分别检查有连接、无连接、心跳变化、手改保留、历史只读、无对应设计块及无公开注释的文档。自动化测试套件未运行。
