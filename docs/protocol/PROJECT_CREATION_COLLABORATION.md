# 新建项目与创作协作

新建先选择游戏、叙事与世界观、剧本、微电影、综合或空白。空白直接名称与位置；其余方向提供领域词条、多选、自定义和可跳过输入，然后名称与位置。快捷词条追加选择，不清空原输入。

私人设想与手改开场白保存于本机浏览器草稿；旧游戏设想及拼装器的手改开场白可恢复。修改选项不覆盖手改开场白，主动重新生成才替换。项目简介只保存设想，不包含协作初始化和完整开场白。普通创建不套用固定预设空文档，后续任务按真实内容组织文档。示例创建保留演示流程。

所有开场白先检查 MCP。存在有效连接时只带短工具检查；未知或未连接时初始化说明在最前。网页版使用独立本机 MCP，不把网页地址或虚拟目录当作本机服务和真实路径。创建完成使用真实 snapshot 调用并等待 open；非空白创建完成后直接展示“复制本项目开场白”面板，依据真实 snapshot 生成。创建前手改要求原样保留为补充；复制时独立追加实际项目身份，以实际身份覆盖旧文本中尚未创建的说明。复制失败选中带身份全文。空白人工模式直接进入工作台。

普通创作使用 cewen_work_begin / documents / write / finish，配合 status / control 自动保存本轮暂定初稿和关键问题。只有明确要求审核时走提案；不替用户作答。既有回答分析仍先分析、等待用户明确开启下一轮。

集成验证：TypeScript、桌面/网页/运行时生产构建已通过。真实浏览器已走通预设、拼装、名称位置与创建；未运行自动化测试、未提交、未发布。完整证据和剩余设备验收见 COLLABORATION_IMPLEMENTATION.md。

## 2026-09-29 分方向拼装与大面积预览

上述全方向共用捷径已替换为每种方向自己的辅助组合。游戏保留探索原型、卡牌构筑、模拟经营和叙事冒险；世界观提供世界起点、角色关系、事件分支与互动叙事；剧本提供人物冲突、场次骨架、对白与短片剧本；微电影提供剧情短片、分镜、声音叙事与纪实观察；综合提供游戏叙事、剧本影像、共享世界与互动影像。空白仍直接进入名称位置。

每个组合显示实际追加词条；已包含时明确提示，无隐式清空或默认采纳。辅助组合、类型与目标、内容与载体、制作条件分四页；目标及时长建议使用当前方向的表达。每种方向独立保存并恢复草稿，切换方向不混入其他领域。迁入的既有草稿词条仍显示并可移除，自定义字段保留。尚未想清楚会实际将协作方式改为“先问我关键问题”。
