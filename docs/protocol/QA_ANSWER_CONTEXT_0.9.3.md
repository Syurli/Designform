# 0.9.3 回答上下文精简验收

使用独立虚构项目人工走查协议，未运行自动化测试套件。夹具为 24 个问题、12 份 DD，包含选择答案、两行自由回答、暂缓及题目反馈，不使用用户真实回答作测试数据。

- 同一快照的旧开场白约 9,045 字符，新版约 270 字符，减少约 97%。这是字符比较，未冒充特定模型 token 实测。
- 精简上下文保留原话、选择与必要背景；只返回相关文档标题，不回传逐题 hash、UUID、图谱与私有工作区。D 短号可按需读取完整正文，文档内链接转换为短号。
- 原 V2 引用在之后采纳候选和改答到 V4 后仍读取 V2。部分范围只返回指定两题；无效版本、失效 D 号和越界题序明确报错。
- 提案只使用 Q/D 短号、读取引用、null 基础哈希与空依赖字典。软件补全正式路径和基础数据，保留 YAML 和原始回答，短链接还原正确；重复请求得到相同候选，简短回执不含候选正文与哈希。
- 虚构提案由人工审核入口成功采纳；后续改答后，旧候选的冲突被保留，不覆盖新回答。

类型检查、桌面／网页／运行时构建以及安装版 CLI／旧 MCP 透传结果在本机安装记录中核对。项目正文和历史未作批量 ID 迁移。
