# 0.9 媒体、生产与格式迁移

## 格式 1 → 2

原项目以原格式继续读取。启用新模块前，由用户明确选择独立父目录，生成升级副本；保留原项目及旧 versions 的字节，不原地改写历史。副本在新修订将当前入口升级为格式 2；旧快照按其原格式读取。

当前候选在切换同身份的项目副本时会清理旧目录的历史与观察缓存。迁移仍须用副本手动验收，不允许直接拿真实项目做首轮验证。

## 媒体存储

新媒体位于 `assets/objects/<sha256>/content.<ext>`，以不可变内容哈希定位。`docs/media/` 保存描述对象；格式 2 快照记录 media 引用映射，不将完整图/音文件每次复制到 versions。原有 `docs/assets/` 仍兼容。

读取必须属于所选当前稿或历史快照，路径与 SHA256 需匹配；格式 2 的引用映射必须与快照正文中的媒体描述一致。导出当前稿/历史/完整包时收集相应媒体并校验。未实现自动媒体清理，不删除历史仍引用的文件。

单文件 64 MiB，基础文件签名白名单为 PNG、JPEG、WebP、GIF、WAV、MP3、Ogg、M4A。签名检查不代替浏览器实际解码，无法解码时显示错误。MCP includeContent 最大 5 MiB；通用生产包参考媒体合计最大 32 MiB，自包含排演包媒体最大 48 MiB。更大项目应分批。整包容量、历史恢复与长期缓存的进一步压力验证尚未完成。

## 生产任务

先预览目标、提示词、参考对象及来源修订，再确认保存固定批次。预览后源修订变化应重新预览。生产任务使用独立 jobId，镜号改变不改变任务身份。

`cewen-production-1` 包含 sourceRevision、目标/画面 ID、固定 prompt、依赖哈希、参考媒体及回导模板。台词生产只输出原台词和表演要求，不能把镜头参数念成旁白。当前 UI 可预览/复制提示词，通用包可手动交给外部工具；逐任务高级提示词编辑与批量生产精细策略仍待完善。

回导使用 `cewen-results-1`，明确 batchId、jobId、candidateId、filename。身份不匹配、路径越界和坏数据必须报错；不能用文件顺序猜对应。媒体登记、候选登记、正式采用是不同阶段。采用时检查目标哈希和生成依赖；旧依据生成的结果保留为候选，但不会悄悄覆盖当前正式内容。

## ComfyUI 候选连接器

仅桌面模式，接受用户指定的本机 HTTP localhost/127.0.0.1 地址。用户选择已审核的 API 工作流并明确选择文本输入节点；工具将固定任务提示词注入该节点。工作流有数量和体积上限，不接受地址凭证、远程 origin、重定向或任意输出路径。

提供连接检查、提交、主动查询历史、收集输出和仅删除尚未运行的排队任务。不会调用全局 interrupt。提交超时或回执不确定时标记 uncertain，禁止自动重试；跨重入保存 submitting 状态，同进程同项目串行操作。收集输出只登记候选，不自动采用。

本次只通过仿真 HTTP 产线检查了协议边界；没有在真实 ComfyUI 和真实模型工作流上完成生产验收。参考图上传、任意工作流自动适配、真实 GPU 执行和完整实时进度不是本候选已验证能力。TTS 提供通用任务导出及音频回导，没有集成某一家真实配音服务。

官方接口依据：ComfyUI Server Routes，https://docs.comfy.org/development/comfyui-server/comms_routes 。
