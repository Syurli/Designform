# 0.9.4 发行验收

0.9.4 合并项目复制锁恢复、大项目性能、策问流程精简和回答上下文优化，沿用公开格式 1 / 2、接口协议 1。

## 已完成的本机检查

- 类型检查、桌面与网页生产构建、运行时打包通过。版本号由 package.json 单一来源提供，锁文件版本同步。
- 作答流程的隔离虚构项目人工界面／协议检查见 [策问流程](QA_INQUIRY_FLOW_0.9.3.md)；来源空锚点、独立反馈、自动汇总、追加改答与重复制行为已核对。
- 24 题／12 份 DD 的隔离人工协议检查覆盖短号原始问答、按需正文、部分范围、失效引用、固定保存版本、提案基准补全、原始回答与头部保留、短链接还原、人工采纳及后续冲突。详见 [回答上下文](QA_ANSWER_CONTEXT_0.9.3.md)。
- 既有 MCP 会话在不重启宿主的情况下实际读取 24 题和按需正文；实际开场白由 7,605 缩到 265 字符，减少 96.5%。这是字符比较，不作为特定模型 token 实测。
- 本机更新程序资源后，公开项目文本逐一一致，项目版本与文档数量保持一致；程序文本资源与构建暂存包一致。私人回答、游戏正文、程序二进制、安装包与开发缓存均未进入仓库。
- 性能分支此前远端 acceptance 失败的原因是人工提案采纳误用 llm 提交身份，触发决定保护。本次已改为用户审核提交，保留候选来源理由和原话校验；隔离人工采纳及冲突检查已通过。

默认不运行自动化测试套件，也未重复此前性能基准。首次解析、长期大资料库、原生输入法与多种硬件表现仍以上线使用和既有性能记录的范围为准。
