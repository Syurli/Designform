# 策问 0.2.4 · 总纲文字与品牌排版

中央总纲取消额外的大底板、粗体大字号和重复的“游戏总纲”副标题。字号、内边距、单行省略以及悬停和选中反馈均沿用普通文档节点，仅保留金色文字作为区别。深色使用柔和金色，浅色使用对比更清晰的金棕色。

总纲仍为星系核心，其文字优先显示；标签位置与其他节点使用相同的避让规则，不再固定在星点下方形成一张大卡片。中央星点、系统关系、既有动画和详情避让保留。

应用栏的“策图标＋问”作为紧凑中文组合，统一垂直中心、字重和间距；英文 Designform 放到同一行作为辅助识别。小窗口隐藏英文，保留中文完整名称与可访问名称。原有图标文件和托盘图标不变。

## 人工验收

1. 查看总纲未选中、悬停及选中状态，应为金色单行文字，尺寸与其他文档标签一致。
2. 点击其他节点或空白，确认中央总纲没有重复副标题，也没有恢复成大卡片。
3. 切换深浅主题，检查金色文字对比与品牌颜色。
4. 切换系统分层、进入关系分析再返回，确认文字与连线位置正常。
5. 查看应用栏，“策”图标与“问”组成一组，英文不再堆在单个汉字下方。

使用类型检查、生产构建和人工浏览器检查，不执行自动化测试套件。视觉效果及原生桌面窗口由用户人工验收。
