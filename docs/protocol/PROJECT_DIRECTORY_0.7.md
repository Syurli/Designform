# 策问 0.7 项目目录交互约定

项目总纲（GDD）是唯一固定根卡片。它始终显示在搜索和目录列表之间，不参与分类列表、层级移动或排序，但可以拖出为正文引用。分类路径独占两栏全宽，可横向滚动；当前项的提示展示完整路径。分类栏保留当前层同级分类，点击名称查看其文档，点击箭头才进入子分类列表。文档有独立路径，列表只呈现当前层；进入四至五级目录时不会逐级缩进并压缩画布。点击路径任一级可直接返回，拖到路径节点表示移入该层级。

## 浏览与私人状态

- 文档、收藏、最近三个视图和跨层搜索继续保留。搜索、收藏和最近视图显示匹配文档，不受当前层级限制。
- 分类路径、文档路径、分页、收藏、最近和置顶仅保存在本机 `localStorage`，不写进正文。
- 历史版本完全只读。`linkOnly` 引用目录副本只允许浏览、搜索、收藏和拖出文档，不显示编辑入口，也不接受内部层级拖放。

## 拖动与键盘菜单

- 条目左侧手柄可以直接拖动；在条目上按住约 250 毫秒也会启用拖动。移动分类或专项文档时，落点的上部、中部、下部分别显示“前面”“放入”“后面”。分类接收文档时只提供“放入”。面包屑和总纲根卡片提供返回上层的落点。
- 分类可在同级排序，也可放入另一个分类；文档可在同级排序、放入另一个专项文档，或放入分类。项目总纲不允许移动。数据层拒绝自身及子树的循环移动和超过允许深度的移动。
- 更多菜单保留“上移”“下移”，另有“升一级”“降一级”。文档无合法上级或上一同级条目时不会改动。F2 可修改文档标题。

## 正文引用拖拽协议

拖动任意文档（含总纲）开始时，`DataTransfer` 写入 `application/x-cewen-document`，JSON 内容为 `{projectId,documentId,path,title,anchor?}`；`text/plain` 为标题。同时在 `window` 发布 `cewen:document-drag-start` 和 `cewen:document-drag-end`，`detail` 为相同文档信息。`path` 是项目内相对路径，不包含用户电脑路径。分类不发布文档引用协议。正文插入由编辑器接收端负责。
