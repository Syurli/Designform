# 实时协作界面

正式 snapshot 保留保存基准，工作稿通过 collaboration.documents 只在目录、阅读与图谱中叠加。被任务占用的文档具有独立服务端工作锁，个人阅读锁按钮不能解除该锁。其他文档继续人工编辑。

当前项目订阅鉴权事件，六秒轮询兜底，切换项目释放旧订阅。任务面板按异常优先显示并发任务，提供定位文档、停止、恢复、撤销和清除异常提示。连接心跳与任务状态分开。

收到占用事件时结束当前输入并保留个人恢复草稿。工作稿不替换标签保存基准；任务结束后保留个人稿，阅读页提供三方文本对比及继续编辑入口。

未执行自动化测试。集成类型检查和桌面/网页构建已通过。

取消、中断、失败任务可通过“查看保留工作稿”显式读取恢复资料，只读展示，不混入正式项目文档。个人草稿连续输入合并后串行写入项目私有草稿，浏览器应急副本即时保存；删除前等待草稿写入，避免迟到请求复活已放弃稿。

Pages 首屏接入本机环境管理面板，正式项目应用后异步部署；接管前检查正文、策问及图谱未保存操作，配对后重读真实路径与正式快照并重建事件订阅。连接开场白根据 integration.mode 切换到本机 MCP 模式。保留任务工作稿响应遵循服务端顶层任务摘要字段。

代码复核：运行工作稿到达时先同步阅读模式再设置预览/画布可见性，避免首次锁定仍隐藏正文。完成但 revision=null 的无变更任务不显示撤销。图谱在 main 重新解析工作正文产生新增 nodes；shared projectWorkView 目前只合并 documents。已在本地真实浏览器核验占位直接进入目录、工作稿只读、新段自动显示和完成后恢复编辑；个人稿三方比较完整点击及真实 Chrome/Edge 权限仍待设备验收。
