# 系统分层排版（0.7.1）

## 阅读规则

- 总纲居顶，顶层分类按公开目录顺序从左向右分栏；横向模式把同一分组转为从上向下的行。
- 同一分类的子分类、文档及小节连续排列。每个父项之后先读完其子分支，再进入同级下一项；子层缩进 24 个场景单位。
- 纵向分类距总纲 130 单位，普通条目间隔 82，小节间隔 54；列宽按标题与最大缩进预留。横向首列距总纲 210，条目间隔 250，分组行高按最大缩进预留。
- 单独归类的小节优先显示在指定分类中，其余小节紧跟来源文档。总纲直属正文和缺少分类的孤立条目共用末栏，不生成虚假的分类节点。
- 总览只显示选定展示父项的归属实线；选中条目时显示它的跨分支关系。全部原始关系继续保留在数据和关系分析中。
- 归属线沿行间与父项侧边走折线，竖向标签统一位于节点右侧，横向标签统一位于节点上方；不再用四个方向轮流躲避来打散阅读顺序。
- 首屏按分类横向占用或横向模式的分组高度取景，不把整条长分支缩进一屏。超宽项目从首栏开始，可右键平移和滚轮缩放。

## 缓存与编辑

分层使用 `layers-v5` 独立坐标键，按方向、公开节点顺序/标题/归属、包含边及可见集合隔离。旧 `layers-v4` 坐标不再覆盖新布局。分类、目录顺序和筛选改变时重新连续排布，普通选择、缩放及返回保持当前布局。超过 500 节点的项目因选择展开额外小节时重新分配槽位。

手工拖动和固定节点仍属于私人摆放；同一结构和筛选范围内可恢复。改变目录结构后重新排布，切回先前结构可恢复该结构的摆放。“自动排布”清理当前范围的记忆，可撤销。星图和设计脑图使用各自原有坐标键。

仅调整视图，不写入 PROJECT.md、正文或正式历史，不修改公开格式版本及最小兼容应用版本。
