# 图谱拖动与镜头切换（0.6）

本说明对应 `src/graph-interaction.ts` 和 `src/graph.ts`。图谱中的空间摆放属于布局；分类、关联与正文链接只有通过二维编辑命令才改变。

## 拖动规则

- 被抓节点直接按指针对应的世界坐标移动。多选节点使用相同位移，保持相对形状；固定节点、总纲、隐藏节点不被带动。
- 未选中的近邻只在当前布局内响应。分类或包含关系产生有限跟随，近距离节点产生柔和避让。普通关联不沿关系网络传播位移。邻居速度和离开原位的距离都有限制，帧间隔限制为 33 毫秒。
- 松手后的邻居最多收敛约 420 毫秒；整个手势结束后记录一次布局和一次撤销。减少动态效果时跳过收敛等待。按 Esc 可恢复手势前布局；导航前先完成待收敛手势。
- 三维模式拖动只改变摆放。二维模式的归类、接端口、插入手工关联仍要求明确的指针落点，并在松手时执行。命中使用按下时的稳定节点及线端位置，邻居的弹性位移不会生成语义操作。摇动断线仍需显式开启，并仅作用于普通手工关联。

## 镜头规则

镜头在目标点、观察方向、镜距三个量上插值。方向沿最短弧旋转；接近对向时使用固定辅助轴。镜距下限为 150，与 OrbitControls 下限一致。节点布局和镜头共享转场进度，概览切换仍为 1150 毫秒，分析视图沿用原有较快节奏。

程序转场时暂停 OrbitControls 的残余阻尼；用户主动操作可接管镜头，结束后恢复阻尼。连续切换从当前屏幕帧重建起点。侧栏或窗口仅改变画布比例时保留现有镜头姿态；转场中的尺寸变化更新目标构图。三维总览快照继续保存用户视角。

## 人工验收

在虚构示例中检查：三维单节点与多选拖动、固定节点和总纲、近邻弹性与松手收敛、Esc 取消、二维分类/端口/手工连线命中和单步撤销；再从背面视角、俯视、大幅缩放连续切换三维/分层，开合侧栏与改变窗口尺寸，分别在正常和减少动态效果模式确认镜头不穿过目标、不回弹、总纲保持最高层。自动化测试套件未运行。
