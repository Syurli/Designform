# 策问 0.7.1 系统分层验收记录

本轮修复系统分层的逐层居中回归：分类分栏、分支连续、子层缩进、标签统一对齐、归属折线及按需显示跨系统关联。开发目录为当前 Designform_Dev，使用独立的虚构示例目录。

## 验证范围

按工程约定未运行自动化测试套件。`npm run build:all`（含类型检查、桌面前端、独立网页、本地运行时）与 Windows x64 便携包构建通过。构建仍提示既有的大体积前端分块和重复依赖引用，不影响完成。

1. 基础示例 39 个条目：检查纵向分类分栏、文档下的小节连续性及横向分组，初始分类标题可读；自动排布可触发撤销记录。
2. 五层虚构目录副本：世界构想 → 地图结构 → 地图框架 → 区域通路 → 山谷捷径连续排列，同级“地图标记”在整个前一分支之后；缩小后可见全部 9 个条目。
3. 选中地图框架，开启“只看相关”后压紧为 3 个条目，清除筛选恢复 9 个条目。详情面板缩窄画布后仍保持标签与连线对应。
4. 首次从星图进入分层、横竖切换、缩放及筛选后检查控制台，无本轮新增警告或错误。

本机发行入口更新与旧包清理另记在忽略目录 `.local/`，不向公开仓库写入用户配置和安装路径清单。

## 边界

大项目允许向下或向右延伸，不能保证所有条目同时放进一屏。手工把节点拖到拥挤区域仍可能触发标签避让隐藏。未穷举所有历史坏数据、超大图谱和系统缩放组合，本记录不代替用户验收。
