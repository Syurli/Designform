# 0.9 创作模块与公开格式

适用：`0.9.0-rc.3` 本地开发候选。此文是实现契约，不表示已完成全部 0.9 任务、已发布或已通过用户手动验收。完整状态见 [任务状态](../tasks/STATUS_0.9.0.md)。

## 共用对象，不按预设锁功能

空白、游戏、叙事、剧本、微电影、综合六种预设只创建起步文档或虚构样例。格式 2 的普通创作文档均可插入全部可编辑模块；问题原始回答、媒体登记和生产回执使用专用服务入口。此限制来自数据职责，不来自项目类型。

新增统一注册项：character、location、map、map-use、storyline、scene、voice、speech、shot、sequence、decision、reference、quest、media、production。原有对白与色板继续保留原编辑器，索引能读取旧 `cewen-dialogue` / `cewen-palette` 块；尚未将其全部迁入新通用表单。

## 权威内容与身份

Markdown 仍是可读的正文；新对象使用 `cewen-object` 围栏。每个对象在项目内只有一个稳定 ID、一个拥有它的文档。修改只替换源文件中对应的围栏，保留无关段落。未识别的 schema/类型保留原文并报告诊断，不静默删除或猜测升级。

````markdown
```cewen-object
schema: 1
id: map-station
type: map
title: 货运站平面图
status: draft
data:
  description: 二维空间示意，不是实际三维坐标。
  points: []
  areas: []
```
````

字段定义、默认值和校验以 `shared/creative/registry.ts` 为准，MCP `cewen://schemas/modules` 可读到同一目录。未知附加字段在普通编辑中保留。对象层哈希用于识别模块变化，文档层哈希用于正式文件并发校验；不能用显示标题或镜号替代身份。

`reference` 保存源对象引用。地图的 `map-use` 保存基础 `mapId` 和当前用途的点、线、区域覆盖层：修改战斗覆盖层不修改剧情或分镜覆盖层。点击编辑共享源与复制为独立对象是不同操作。此候选主要提供坐标表单与二维预览，尚不包含成熟的地图直接拖拽编辑器。

显式模块引用可投影为拥有文档之间的知识关系，不根据名字相似、二维位置或星图距离生成设计事实。复杂关系专用可视化与大规模性能仍待验证。

## 文档和布局

`docs/creative/` 可保存普通模块文档，`docs/quests/` 保存 Quest，`docs/questions/` 继续保存独立问题。媒体描述与生产批次也使用公开 Markdown，不放进用户必须依赖的软件数据库。`docs/layouts/` 仍只保存文档展示位置、尺寸等伴随数据。

场次、镜头、台词和排演时间是正式创作数据，不得放入仅供界面布局的字段。一个镜头可以有多个连续画面；一个画面可以有多份素材候选，二者不能混用。

## 排演

`sequence` 的 items 引用 shot，audio 引用 speech。时长使用整数毫秒；镜头内可有多张画面，声音可跨越切镜。排演进入时编译并冻结当前修订，不随异步素材回导突然换图。

已实现审阅、观影、台词三种布局及播放/暂停、定位、速度、静音、字幕、范围循环。缺图缺声音时保留文本和警告。暂停提问记录镜头/画面/使用实例及局部时间。导出为自包含 HTML 排演包，不是 MP4；该轻量出口不等于专业剪辑软件。

## 万类接口

`cewen-wanlei-exchange-1` 导出项目、修订、对象及源哈希；二维坐标标记 normalized-2d，实际三维摄影机变换为 null。`cewen-wanlei-result-1` 预检返回的对象映射，区分 matched/stale/missing，不直接写回创作内容。当前没有真实万类连接器，不能将文件契约视为已经实现三维预演。
