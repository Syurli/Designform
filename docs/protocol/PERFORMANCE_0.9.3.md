# 0.9.3 本地性能修订

## 问题与修复范围

原界面同时以 4 秒和 6 秒间隔读取正式快照；6 秒路径不检查变化便调用完整界面更新。大资料库在空闲阅读时仍重解析目录、重建预览和更新图谱。服务端每次读取也重新解析全部 Markdown 并检查链接；问题阅读将同一题重复解析为背景、选项、回答、解释和决定记录。

- 事件、聚焦、人工校验和 4 秒补扫共用一个在途刷新。读取期间的新事件或人工完整校验排队补读，避免吞掉最后一次协作写入；删除第二个定时器。
- 正式指纹、修订、恢复标记、诊断及协作投影都不变时保持界面实例。工作稿、任务状态或锁改变仍更新；旧项目请求不覆盖新项目或历史阅读。
- 服务端每次仍读取公开文件并计算内容哈希；仅相同指纹复用纯内容解析与链接诊断。每次独立克隆，再投影文档时间和本次历史、事务、批次诊断。最多保留八个项目结果，重新打开、移除或关闭服务时释放。
- 阅读目录按当前快照、项目入口、正文及元数据缓存知识结构。个人草稿正文变动，即使正式哈希不变也使缓存失效。
- 问题章节共用一次原文解析，按正文文本失效；最多 128 条且总字符不超过 100 万。标题层级、正文偏移和原始回答追加规则不变，返回选项仍使用独立数组。

本轮保留原有页面排版、动画和保存协议；没有修改真实项目文档、答案或历史。缓存始终只用于读取投影，不能作为正式保存基准。

## 本机测量

使用用户授权项目的公开资料副本，88 份 docs Markdown，加 PROJECT.md 共 89 份、约 637 KiB、96 个知识条目、484 条关系和 48 道问题。副本具有独立项目库与编辑器工作区，未复制或读取真实项目 `.cewen/`。私人资料及测量截图不进入软件仓库。

| 读取工作 | 修复前 | 修复后 | 口径 |
| --- | ---: | ---: | --- |
| 后台重复读取 | 423.5 ms | 44.9 ms | 预热后五次读取的中位数 |
| 48 题解析 | 80.7 ms | 0.10 ms | 相同正文预热后五次完整问询读取的中位数 |
| 48 题首次解析 | 136.1 ms | 15.4 ms | 单次，受运行环境影响 |
| 阅读界面空闲长任务 | 13 秒内三次，每次约 2.2–2.3 秒 | 同一窗口内未观察到 | Edge 本机生产资源、50 ms 长任务门槛 |
| 项目策问打开 | 271 ms | 79 ms | 同机生产页面一次打开，非稳定基准 |
| 作答后空闲长任务 | 9 秒内出现约 1.8–1.9 秒的停顿 | 同一窗口内未观察到 | 草稿在定时同步后仍完整保留 |

48 道真实问题的背景、选项、回答、解释、决定字段和条件可用状态在修复前后完全一致（本机输出摘要核对）。后台改善来自避免约 206 ms 全文解析和 173 ms 链接诊断的重复执行，不代表首次打开和所有交互加速同一倍数。

## 验收与限制

类型检查、桌面及网页生产构建、桌面运行时和 Windows 安装目录构建已通过；构建目录包含本验收记录。隔离页面已核对文档阅读、进入项目策问、填写个人草稿及定时同步后的草稿保留，没有浏览器脚本错误。安装落盘后另以 LOCAL_BUILD.json 记录来源与入口核对。按工程约定未运行自动化测试套件；本轮执行的是有界性能回放与界面、协议核对。

公开副本不包含用户真实的私有草稿、事务恢复记录或七轮历史的完整运行状态；尚不能据此保证所有长期使用路径、超大图片文档或原生中文输入法表现。后续观察真实工作区时，优先记录具体操作耗时，不以删除历史或拆散用户设计作为默认优化手段。
