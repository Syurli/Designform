# 前题导航与状态筛选（0.9.4.1）

## 前题

条件未满足时，作答区及汇总显示可点击的“前题‘题名’回答后可答”，不展示内部 ID。指定选项的条件保留方案要求。按钮使用正式问题身份定位，允许跨分类、来源、搜索和状态筛选；归档前题临时显示归档范围。缺失前题只给出简短说明，不创建无效跳转或解除条件。

跳转前保留个人草稿；前题页及其汇总提供返回原题／原汇总入口，返回恢复原搜索、状态筛选、分类、来源、归档开关与轮次。连续前题支持逐层返回；循环关联给出调整提示。返回栈只在当前策问页面有效，重新打开页面仍按既有会话恢复回答与当前位置。

同轮前题的有效草稿用于预显条件，返回后即可继续回答。跨轮前题必须在其本轮汇总明确保存后才影响另一轮，不因点击返回隐式保存其他轮回答。目录也逐轮判断条件，避免显示状态与实际权限不一致；无草稿轮次复用只读快照，保留大项目性能优化。

## 筛选

| 筛选 | 包含 |
| --- | --- |
| 全部 | 当前范围问题，是否含归档由既有开关控制 |
| 待答 | 未回答、暂缓、需要复核的旧回答 |
| 已答 | 有效个人回答草稿、已保存项目回答、已反馈的问题 |

草稿显示“已答 · 待保存”，项目回答显示“已答”；变化后的旧回答显示“需复核”，并回到待答。反馈题保留“题目有问题”标记，空白题不假算已答。待答计数与筛选共用规则。旧“本机回答”筛选迁为已答，旧“题目更新”迁为待答，仅调整个人浏览偏好，不清除或改写答案。

填写、切题及返回仍只保留本机草稿；汇总末尾复制或预览开场白时保存当前轮。分析入口与短号交接规范不变，不添加逐题 hash 或长编号。来源、原话和历史记录保留。
