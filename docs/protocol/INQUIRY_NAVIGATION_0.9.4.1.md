# 自动问答与轮次（0.9.4.1）

## 作答

选择或填写即算已答，自动记录到项目；连续输入合并写入，切题与退出触发队列，无需保存、提交、勾选或逐题复核。已答表单直接修改，改答追加原话，清空变为暂缓；问题反馈保留独立按钮。记录失败保留本机应急输入并自动重试，复制开场白须等本轮记录完整，不能声称模型已读取未落盘内容。临时示例只在内存记录。

目录和左上策问数量使用同一规则，输入时立即更新，不等切题或写入结束。待答包含空白和暂缓；已答包含选择、文字与问题反馈。归档不计入全项目待答。旧“本机回答”“题目更新”筛选只迁移个人偏好，不清除回答。

## 前题

条件未满足时显示可点击题名，支持跨分类、来源、搜索、筛选及轮次；缺失前题只说明，不产生失效入口。前题页及汇总可返回原题／原汇总，恢复原范围和归档开关；多层返回支持，循环关联提示调整。前题的输入用于条件预显，自动记录，无需跨轮另行保存。

## 轮次

一轮是一次完整问题批次，同批跨文档共用轮次身份。身份为 questId 与 roundId，独立问题缺省取 round 名称；不同 Quest 不误合并。已回答的问题保留题意和原轮次，修改、修正前提与追问使用新问题 ID、新轮，可用 follows 关联旧题。模型可补充解释与建议，不改写用户原话；来源、分析或前题更新不触发逐题复核，不把已答题重新变成待答。服务阻止正式已答题改题意或移动轮次，普通发题阻止往已答轮继续追加问题。

轮次汇总列出项目所有轮次，包含已答、未答及归档历史，每轮一张收起的卡片，显示题数、已答、暂缓与问题反馈。选择一轮才展开该轮问答，不展开全项目问题清单。移除或非法外部改题的未完成输入保留在折叠的旧题记录中，不混入新题。

## 交接

答完一轮直接复制开场白，或预览编辑；复制只等待自动记录队列，不是人工提交，也不再次追加相同回答。短版本引用固定到复制时的公开问答，范围仅为所选轮；其他轮回答不会混入。保持 Q/D 短号和按需正文读取，不展开 UUID、hash 或重复轮次清单。LLM 讨论后等待用户明确同意，再发布新轮问题。复制与自动记录不代表已连接模型或授权续轮。
