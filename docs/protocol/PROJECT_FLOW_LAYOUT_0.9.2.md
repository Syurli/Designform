# 项目流程、弹窗与章节定位（2026-09-29）

## 实现边界

- 现有游戏、叙事与世界观、剧本、微电影、综合、空白方向保持。每种非空白方向具有四组明确列出词条的辅助组合、方向对应的目标及制作时长建议。组合只追加，重复点击会提示已包含；细项可逐项移除，自定义和既有草稿保留。
- 第二步宽屏采用约45%设想与55%可编辑全文；展开预览使用全部内容区。左侧辅助组合、类型与目标、内容与载体、制作条件分四个标签页，左区和正文独立滚动。每种方向独立保留草稿，切换时不混入其他领域。窄窗口纵向排列，仍可展开全文。连接心跳不重建面板，手改正文不被选项覆盖。
- appForm、新建项目及文档预设库的标题和底部操作留在内容区之外；连接、协作及旧工作面板的标题栏吸附。项目身份设置同样保留标题和退出。未扩大重排到正文工作台。
- 八种学习示例使用原生单选卡片，显示学习内容、练习及选择反馈，保留临时会话和另存为行为。
- 文档目录的章节身份完整传入打开流程。文档视图按公开锚点定位标题并展开父链；自由画布将独立锚点附着到下一张内容卡，以当前缩放平移到目标，展开折叠父链。使用短暂强调和键盘焦点提示。找不到旧锚点时明确告知，不能用同名文字猜测章节。
