# 0.9.4.1 检查记录

日期：2026-10-07。源码共用于桌面与网页；默认不运行自动化测试套件。

## 已完成

- 类型检查、桌面与网页生产构建、运行时打包通过。
- 独立虚构项目：搜索“词条”并筛选待答，隐藏前题；键盘 Enter 打开跨来源前题，题名及表单正常。
- 填写前题后返回原题，恢复搜索和筛选、解锁同轮后题。选择及原话自动写入正式问题，重新加载仍可直接修改。
- 汇总提供前题入口；归档前题临时显示归档开关，返回恢复原汇总及开关。
- 缺失前题显示简短说明，无失效入口，不解除作答条件。
- 无保存或提交按钮，真实 answers 接口自动记录两题；待答数从 6 即时降到 4，清空回答恢复待答。
- 直接复制短开场白，包含公开 V3 与本轮已答 2／暂缓 4，不重复追加回答。
- 分析与来源更新真实提交返回 200／V4，旧题仍已答；修改已答题题意被服务以 ANSWERED_QUESTION_IMMUTABLE 拒绝。
- 往已答轮追加问题被 ROUND_ALREADY_ANSWERED 拒绝；使用新题、新轮发布返回 200／V5。
- 汇总列出三轮卡片，包含旧轮已答和新轮未答；默认不展开问题，进入某轮才显示该轮问答。
- 源码复核：自动记录串行、后续输入不被旧请求清除；跨轮前题无需额外保存，交接仅含所选轮；输入法组合与实际外部题意变化分别处理。旧个人筛选有明确迁移。
