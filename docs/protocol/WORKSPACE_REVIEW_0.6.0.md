## 已完成范围

- 雾纸与墨石两套主题覆盖窗口、菜单、文档、对白及色板界面。当前项目图标打开独立设置，可设置名称、图标、简介与备注；项目库仍是独立入口。
- 项目目录以分类与文档分栏呈现，支持分类分页、跨分类搜索、收藏和最近访问；条目可改名、别名、归组、颜色与排序。分类颜色同步用于图谱。项目面板在所有窗口宽度都可手动收起、展开并记住选择，快捷键为 `Ctrl + \`。
- 同一份 Markdown 文档提供正文、排版和注释。标题可折叠后续内容；图片可缩放、排版；底纹覆盖整个策划案阅读或编辑面板，四周柔和淡出，方格、横线、点阵和素纸选择在阅读与编辑间共用。
- 注释支持笔、荧光笔、箭头、文字和贴图，可移动、缩放、旋转与调整层级。共享注释与私人注释分开；公开布局与笔画跟随稳定块 ID，并纳入正式版本。
- 正文内保留对白可点选预览，独立蓝图编辑器编辑节点与分支。色板可手选颜色、读取本机图片、提取 3—12 个主要颜色、框选局部或点选取色；正式设计色与源图近似面积分开。
- 文档底部即时统计；项目统计页读取当前已保存修订，可搜索和导出 CSV。图谱增加阻尼跟随、避让与更稳定的视角过渡，3D 摆放与 2D 结构编辑保持分离。

## 人工复验边界

本轮没有对中文输入法的所有组合、所有图片格式、低性能 GPU、3D 背面视角连续快切、所有 2D 端口拖接组合和各浏览器文件夹授权行为做穷举验证。上述复杂操作仍需在用户实际设备与独立示例中复验。色彩占比是采样像素的近似结果，不代表主观视觉权重。

正文、公开布局与共享注释按同批版本提交；个人纸张、面板显隐和私人注释不进入正式策划版本。真实游戏接入继续通过独立协作流程进行。
