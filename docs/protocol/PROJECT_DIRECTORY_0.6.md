# 项目目录组件（0.6）

`src/project-directory.ts` 提供 `ProjectDirectory`。调用方传入容器、当前 `ProjectSnapshot`、选中和分类回调、提交结果回调、错误回调；可选 `onQuery/getQuery/getGroup/getSelected` 用于与图谱、卡片筛选同步。`render()` 接收最新快照并保持当前搜索输入焦点、选区、分类页与列表滚动位置；离开页面调用 `dispose()`。

侧栏固定“文档 / 收藏 / 最近”三个视图。分类列每页显示八个普通分类，置顶分类位于页码上方；“全部”和需要时出现的“未归组”固定可见。搜索跨所有分类，匹配文档名、公开别名、分类名及章节名。总纲在全体文档顶部，目录不显示文档类型方块或 GDD/DD 尾缀。章节可以在文档行下展开。

改名、别名和条目颜色写回文档 Markdown；旧名称是否保留为别名由用户明确选择。归类通过 `graphChanges` 计算公开变更。可在侧栏新增分类、调整分类顺序、修改名称与颜色；这些数据写在 `PROJECT.md` 的 `systems` 字段中，并在同一提交里移除旧总纲的 `systems` 副本。文档顺序写入 `PROJECT.md` 的 `documentOrder` 映射。菜单提供上移/下移，也可以拖到同行改变顺序、拖到分类改变归属。以上操作都由 `commitProject` 原子提交并受版本及哈希校验。

收藏、最近访问、分类置顶、当前页和当前视图只保存在按项目 ID 隔离的 `localStorage` 中，不写入公开设计文件。历史快照不允许编辑。调用方负责将目录组件安置在侧栏并将提交后的快照同步给图谱和其他工作区。

人工验收：准备九个以上分类，检查翻页与置顶；在其他分类中搜索别名和章节；检查 F2、双击名称、菜单改名和保留旧名别名；改分类和条目颜色后核对目录与图谱；拖动顺序及归属后检查版本快照和撤销/恢复；切换项目后检查本地收藏与最近记录隔离。自动化测试套件未运行。
